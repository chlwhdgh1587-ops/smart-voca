## 4. 시스템 범위 (SS)

### 4.1 포함 범위 (In Scope)

- 단어장 관리 (단어 등록·수정·삭제)

- 복습 일정 관리 (같은 세션 재시험, 다음 날 복습)

## 6. 주요 기능 개요

상세 기능과 비기능 요구사항은 요구사항 명세서에서 정의한다. 여기서는 ID만 부여한다.

| ID | 기능 | 설명 | 관련 BR |
|----|------|------|---------|
| FR-01 | 단어 등록·수정·삭제 | 단어와 뜻을 관리하고, 예문은 선택 입력한다 | BR-01 |
| FR-02 | 암기 학습 | 하루 20개 단어를 객관식으로 출제하는 학습 세션을 진행한다 | BR-01, BR-02 |
| FR-03 | 복습 스케줄링 | 세션 내 틀린 단어는 같은 세션에서 재시험하고, 맞힌 단어와 틀린 단어 모두 다음 날 복습 대상으로 제시한다. 복습 세션에서는 연속 3회 정답까지 반복하며, 세션이 끝나면 복습 대상을 해제한다 | BR-03 |
| FR-04 | 학습 기록 조회 | 학습 횟수, 정답률 등을 보여준다 | BR-01, BR-02 |
