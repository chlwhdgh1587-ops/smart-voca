## 1. 변경 요약

| 구분 | 테이블 | 변경 |
|------|--------|------|
| 유지 | `word` | 변경 없음. 모든 회원이 함께 쓰는 단어장 |
| 변경 | `word_state` | 기본키를 `word_id` → `(user_id, word_id)`로. 행은 학습을 시작할 때 만듦 (등록 때 만들지 않음) |
| 변경 | `study_session` | `user_id` 열 추가 |
| 변경 | `attempt` | `user_id` 열 추가 |
| 신규 | `app_user` | 회원 (도전) |
| 신규 | `user_setting` | 회원별 설정 (도전) |
| 신규 | `exam_session` | 시험 한 회차 |
| 신규 | `exam_item` | 시험 문항 단위 이력 |

외래키는 `PRAGMA foreign_keys = ON`으로 켠다. `user_id`는 이관 과정 때문에 `app_user`를 참조하지 않는다 (회원 번호 1은 이관된 기록과 함께 쓰인다).

## 2. 테이블 정의

### 2.1 `app_user` — 회원

| 열 | 타입 | 제약 | 설명 |
|----|------|------|------|
| id | INTEGER | PK, AUTOINCREMENT | 회원 번호 |
| username | TEXT | NOT NULL, UNIQUE | 소문자 영문·숫자·밑줄, 3~20자 |
| password_hash | TEXT | NOT NULL | werkzeug 해시. 원문 저장 금지 (VOCA-FR-042) |
| is_public | INTEGER | NOT NULL, DEFAULT 0, CHECK (0,1) | 학습 기록 공개 여부 (VOCA-FR-052) |
| created_at | TEXT | NOT NULL | ISO 시각 |

### 2.2 `user_setting` — 회원별 설정

| 열 | 타입 | 제약 | 기본값 | 설명 |
|----|------|------|--------|------|
| user_id | INTEGER | PK | — | 회원 번호 (행이 없으면 기본값) |
| daily_target | INTEGER | NOT NULL | 20 | 하루 신규 단어 수 (5~50) |
| review_ratio | INTEGER | NOT NULL | 100 | 복습 대상 중 낼 비율 (50 또는 100) |
| exam_count | INTEGER | NOT NULL | 10 | 시험 문제 수 (5, 10, 20) |
| exam_direction | TEXT | NOT NULL | 'mix' | en2ko, ko2en, mix |
| exam_form | TEXT | NOT NULL | 'mix' | choice, short, ox, mix |

### 2.3 `word` — 단어 (공용)

| 열 | 타입 | 제약 | 설명 |
|----|------|------|------|
| id | INTEGER | PK, AUTOINCREMENT | |
| english | TEXT | NOT NULL, UNIQUE | 소문자, 앞뒤 공백 제거 (정규화) |
| meaning | TEXT | NOT NULL | 뜻 |
| example | TEXT | | 예문 (선택) |
| created_at | TEXT | NOT NULL | |

### 2.4 `word_state` — 회원별 학습 상태

| 열 | 타입 | 제약 | 설명 |
|----|------|------|------|
| user_id | INTEGER | PK 일부, NOT NULL | 회원 번호 |
| word_id | INTEGER | PK 일부, NOT NULL, FK → word(id) ON DELETE CASCADE | 단어 |
| consecutive_correct | INTEGER | NOT NULL, DEFAULT 0 | 연속 정답 수. 3 이상이면 완벽 암기 (FR-02.4) |
| first_studied_on | TEXT | | 처음 신규로 공부한 날짜. 신규 후보 판정에 쓴다 |
| last_studied_on | TEXT | | 마지막 학습 날짜 |
| in_review | INTEGER | NOT NULL, DEFAULT 0 | 복습 대상 표시 (FR-03) |

행은 회원이 그 단어를 처음 답할 때 `INSERT ... ON CONFLICT DO UPDATE`로 만든다.

### 2.5 `study_session` — 학습 세션

| 열 | 타입 | 제약 | 설명 |
|----|------|------|------|
| id | INTEGER | PK, AUTOINCREMENT | |
| user_id | INTEGER | NOT NULL | 회원 번호 |
| session_date | TEXT | NOT NULL | 학습 날짜 (YYYY-MM-DD) |
| started_at | TEXT | NOT NULL | 시작 시각 |
| finished_at | TEXT | | 끝난 시각. 재시작으로 끊기면 닫힘 |
| new_target | INTEGER | NOT NULL | 세션을 시작할 때 남아 있던 신규 목표 수 |

### 2.6 `attempt` — 암기 답안

| 열 | 타입 | 제약 | 설명 |
|----|------|------|------|
| id | INTEGER | PK, AUTOINCREMENT | |
| session_id | INTEGER | NOT NULL, FK → study_session(id) ON DELETE CASCADE | |
| user_id | INTEGER | NOT NULL | 회원 번호 (FR-014) |
| word_id | INTEGER | NOT NULL, FK → word(id) ON DELETE CASCADE | |
| block | TEXT | NOT NULL, CHECK (new, review) | 신규 또는 복습 블록 |
| selected_meaning | TEXT | NOT NULL | 고른 뜻 |
| is_correct | INTEGER | NOT NULL, CHECK (0,1) | 정오 |
| attempted_at | TEXT | NOT NULL | 날짜와 시각. 앞 10자가 날짜 |

일차(FR-011)는 저장하지 않고, `block='new'` 기록이 있는 날짜를 정렬해 계산한다.

### 2.7 `exam_session` — 시험 한 회차

| 열 | 타입 | 제약 | 설명 |
|----|------|------|------|
| id | INTEGER | PK, AUTOINCREMENT | 회차 번호 |
| user_id | INTEGER | NOT NULL | 회원 번호 (VOCA-FR-043) |
| started_at | TEXT | NOT NULL | 출제 시각 |
| finished_at | TEXT | | 마지막 문항에 답한 시각. NULL이면 진행 중 |
| question_count | INTEGER | NOT NULL | 문제 수 |
| direction | TEXT | NOT NULL, CHECK (en2ko, ko2en, mix) | 설정한 방향 |
| form | TEXT | NOT NULL, CHECK (choice, short, ox, mix) | 설정한 형식 |

### 2.8 `exam_item` — 시험 문항 (문항 단위 이력, VOCA-FR-026)

| 열 | 타입 | 제약 | 설명 |
|----|------|------|------|
| id | INTEGER | PK, AUTOINCREMENT | |
| exam_id | INTEGER | NOT NULL, FK → exam_session(id) ON DELETE CASCADE | 회차 |
| position | INTEGER | NOT NULL | 문항 순서 (1부터) |
| word_id | INTEGER | NOT NULL, FK → word(id) ON DELETE CASCADE | 단어 |
| direction | TEXT | NOT NULL, CHECK (en2ko, ko2en) | 이 문항의 실제 방향 (섞기면 문항마다 다름) |
| form | TEXT | NOT NULL, CHECK (choice, short, ox) | 이 문항의 실제 형식 |
| prompt | TEXT | NOT NULL | 화면에 보인 문제 (영단어 또는 뜻) |
| options_json | TEXT | | 4지선다 보기 목록(JSON), OX는 제시된 뜻 한 개, 단답은 NULL |
| correct_answer | TEXT | NOT NULL | 정답. OX는 'O' 또는 'X' |
| selected_answer | TEXT | | 내 답. 답하기 전에는 NULL |
| is_correct | INTEGER | CHECK (0,1) | 정오. 답하기 전에는 NULL |
| answered_at | TEXT | | 답한 시각. NULL이면 아직 안 푼 문항 |

현재 문항은 `answered_at IS NULL`인 것 중 `position`이 가장 작은 행이다. 서버를 재시작해도 DB에서 이어 풀 수 있다.

## 3. 주요 질의 규칙

| 용도 | 규칙 |
|------|------|
| 신규 후보 | `word`에서 회원의 `word_state.first_studied_on`이 NULL인 단어를 id 순으로 |
| 복습 대상 | 회원의 `in_review=1`, 또는 자주 틀린 단어(회원의 답안 중 `is_correct=0`이 2회 이상, 학습 시작 후, 오늘 공부하지 않음). 복습 비율 적용 |
| 완벽 암기 | `word_state.consecutive_correct >= 3` |
| 자주 틀린 단어 | 암기 답안 틀린 횟수 + 시험 문항 틀린 횟수 합산 상위 N개 |
| 시험 가중치 | 안 본 단어 +2, 틀린 적 있음 +3, 마지막 출제가 7일 이상 전 +1 (기본 1) |
| 시험 추이 | `finished_at`이 있는 `exam_session`만, 회차별과 날짜별 정답률 |

## 4. v1 → v2 이관 규칙 (`db.init_schema`)

1. `word_state`에 `user_id` 열이 없으면 v1로 판정한다.
2. v1의 `word_state`, `study_session`, `attempt`를 `*_v1` 이름으로 바꾼다.
3. v2 테이블을 모두 만든다.
4. v1 행을 옮긴다. `user_id`는 모두 **1**로 넣는다. `study_session.id`와 `attempt.id`는 그대로 유지해 연결을 보존한다.
5. `*_v1` 테이블을 지운다. 이관 중에는 외래키 검사를 끈다.

검증: 실제 백업 DB(단어 120, 학습 상태 120, 세션 2, 답안 51)를 이관해 행 수와 외래키 위반 없음을 확인했다 (`tests/test_settings_and_migration.py`). 원본 백업은 `data/backup_smartvoca_before_v2_261125.db`에 있다 (Git 제외).

## 5. 인덱스와 성능

- 2,000 단어 규모에서 모든 질의는 전체 테이블 스캔으로도 충분하다. 별도 인덱스는 두지 않았다.
- 필요해지면 `attempt(user_id, block, attempted_at)`를 먼저 검토한다.
