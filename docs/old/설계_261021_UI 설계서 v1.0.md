# 스마트보카 UI 설계서

**파일 위치**: `docs/old/설계_261021_UI 설계서 v1.0.md`
**작성일**: 2026-10-21
**버전**: v1.0 (초안)
**설명**: 교실에서 쓰는 스마트보카의 화면 구성, 흐름, 표시 규칙을 정의한 UI 설계서

---

## 1. 설계 원칙

- 교실 프로젝터와 학생 PC 화면에서 모두 읽히도록 글자와 버튼을 크게 한다 (NFR-01).
- 정답과 오답은 색과 글자를 함께 표시한다 (색맹 사용자 고려).
- 한 화면에 할 일 하나만 둔다.

---

## 2. 화면 목록

| 화면 ID | 경로 | 이름 | 연결 기능 |
|---------|------|------|-----------|
| S1 | `/` | 홈 | 전체 |
| S2 | `/study` | 학습 | FR-02, FR-03 |
| S3 | `/study/done` | 세션 완료 | FR-04.2 |
| S4 | `/words` | 단어 관리 | FR-01 |
| S5 | `/report` | 학습 기록 | FR-04 |

---

## 3. 화면 흐름

```
S1 홈 ──[학습 시작]──▶ S2 학습 ──(모든 문제 완료)──▶ S3 세션 완료 ──▶ S1
 │
 ├──[단어 관리]──▶ S4 단어 관리 ──▶ S1
 └──[학습 기록]──▶ S5 학습 기록 ──▶ S1
```

---

## 4. 화면별 구성

### S1 홈

```
┌──────────────────────────────────────┐
│  스마트보카                            │
│                                      │
│  오늘의 학습                           │
│  · 복습 대상      12 개                │
│  · 오늘 신규 남은 목표  20 개           │
│                                      │
│        [ 학습 시작 ]                  │
│                                      │
│  [ 단어 관리 ]     [ 학습 기록 ]        │
└──────────────────────────────────────┘
```

- 서로 다른 뜻의 단어가 4개 미만이면 학습 시작 버튼 대신 "서로 다른 뜻의 단어를 4개 이상 등록하세요" 안내와 단어 관리 버튼을 표시한다 (ADR-004).
- 할 일이 없으면 "오늘 할 학습이 없습니다"를 표시한다.

### S2 학습

```
┌──────────────────────────────────────┐
│  복습 3/12                 진행 3/32   │
│  ──────────────────────────           │
│                                      │
│              apple                   │
│                                      │
│  ( ) 사과                             │
│  ( ) 바나나                           │
│  ( ) 포도                             │
│  ( ) 오렌지                           │
│                                      │
└──────────────────────────────────────┘
```

- 보기는 4개이며 버튼 하나를 누르면 바로 제출한다.
- 제출 후 1초 이내에 결과를 표시한다 (NFR-01).
  - 정답: "정답입니다" 문구와 초록 배경
  - 오답: "오답입니다. 정답: 사과" 문구와 빨간 배경. 같은 단어가 이 세션 안에서 다시 나온다고 알린다.
- 결과 표시 후 "다음" 버튼을 누르면 다음 문제로 넘어간다. 키보드 숫자 키 1~4도 보기 선택에 쓸 수 있다.
- 진행 표시는 블록별로 `복습 n/N`, `신규 n/N`으로 나눠 표시한다. 재시험으로 추가된 문제는 전체 수에 포함하지 않는다.

### S3 세션 완료

```
┌──────────────────────────────────────┐
│  오늘의 학습 완료                      │
│                                      │
│  학습 단어   20 개                     │
│  정답률      85.0 %                   │
│  완벽 암기   48 개                     │
│  복습 대기   32 개                     │
│                                      │
│        [ 홈으로 ]                     │
└──────────────────────────────────────┘
```

### S4 단어 관리

```
┌──────────────────────────────────────┐
│  단어 관리                             │
│                                      │
│  영어 [__________]  뜻 [__________]   │
│  예문(선택) [______________________]  │
│             [ 등록 ]                  │
│                                      │
│  #  영어      뜻          [수정][삭제]   │
│  1  apple    사과          [수정][삭제]   │
│  2  banana   바나나        [수정][삭제]   │
│                                      │
│  [ 홈으로 ]                           │
└──────────────────────────────────────┘
```

- 중복 영어 단어는 등록하지 않고 "이미 등록된 단어입니다"를 표시한다.
- 삭제는 확인 화면을 거친다. 확인 문구에 "학습 기록도 함께 삭제됩니다"를 넣는다 (프로세스 설계서 6절).

### S5 학습 기록

```
┌──────────────────────────────────────┐
│  학습 기록                             │
│                                      │
│  날짜        학습 단어  정답률           │
│  2026-10-21    20      85.0 %          │
│  2026-10-20    20      78.5 %          │
│                                      │
│  완벽 암기 48 개   복습 대기 32 개        │
│                                      │
│  [ 홈으로 ]                           │
└──────────────────────────────────────┘
```

- 기록이 없으면 "아직 학습 기록이 없습니다"를 표시한다.

---

## 5. 표시 규칙

| 항목 | 규칙 |
|------|------|
| 글자 크기 | 영어 단어는 가장 크게, 보기는 본문보다 크게 |
| 정답 표시 | 글자와 배경색을 함께 사용 |
| 숫자 | 정답률은 소수 첫째 자리까지 % |
| 날짜 | `YYYY-MM-DD` |
| 오류 메시지 | 화면 상단에 한 줄로 표시 |
