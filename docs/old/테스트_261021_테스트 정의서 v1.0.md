## 1. 테스트 범위

| 대상 | 방법 | 근거 |
|------|------|------|
| 단어 관리 (FR-01) | 단위 테스트 (메모리 DB) | 요구사항 명세서 3장 |
| 학습 세션 (FR-02, FR-03) | 단위 테스트 (메모리 DB) | 요구사항 명세서 3장, 5장 수용 기준 |
| 기록 집계 (FR-04) | 단위 테스트 (메모리 DB) | 요구사항 명세서 3장 |
| HTTP 라우트 | 테스트 클라이언트 흐름 검증 (수동 실행) | 아키텍처 설계서 5절 |
| 화면 표시 | 수동 확인 | UI 설계서 4절 |

## 2. 자동 테스트 목록 (20개)

### 2.1 단어 관리 (`tests/test_word_service.py`, 6개)

| 테스트 | 기능 ID | 검증 내용 |
|--------|---------|-----------|
| test_add_word_normalizes_english_and_creates_state | FR-01.1 | 영어를 소문자와 공백 제거로 정규화하고 학습 상태 행을 만든다 |
| test_duplicate_english_is_rejected_ignoring_case | FR-01.1 | 대소문자만 다른 중복 단어를 거부한다 |
| test_empty_meaning_is_rejected | FR-01.1 | 뜻이 비어 있으면 거부한다 |
| test_update_keeps_learning_state | FR-01.2 | 수정해도 연속 정답 수가 유지된다 |
| test_delete_removes_state_and_attempts | FR-01.3 | 삭제하면 학습 상태와 답안 기록이 함께 지워진다 |
| test_delete_missing_word_raises | FR-01.3 | 없는 단어 삭제는 오류를 낸다 |

### 2.2 학습 세션 (`tests/test_study_service.py`, 11개)

| 테스트 | 기능 ID | 검증 내용 |

| test_start_requires_four_distinct_meanings | FR-02.2 (ADR-004) | 뜻이 같은 단어만 있으면 시작하지 않는다 |
| test_new_block_takes_words_in_registration_order | FR-02.1 | 신규 단어를 등록 순서대로 고른다 |

| test_wrong_answer_is_requeued_and_resets_streak | FR-02.3, FR-02.4 | 틀리면 큐 끝에 다시 넣고 연속 정답 수를 0으로 바꾼다 |
| test_new_block_correct_answer_is_not_repeated | FR-02.3 | 신규 블록에서 맞힌 단어는 같은 세션에 다시 나오지 않는다 |
| test_review_block_repeats_until_three_in_a_row | FR-03.2 | 복습 블록에서 연속 3회 정답이 될 때까지 반복한다 |
| test_review_targets_are_released_after_review_block | FR-03.3 | 복습 블록이 끝나면 복습 대상이 해제된다 |
| test_same_day_restart_does_not_repeat_finished_words | FR-02.1 | 같은 날 끝낸 뒤 다시 시작해도 끝낸 신규 단어는 나오지 않는다 |
| test_restart_closes_unfinished_session_and_keeps_review_targets | FR-03.1, 프로세스 설계서 1절 | 재시작하면 미완료 세션을 닫고, 복습 대상은 유지한다 |

## 4. 수동 확인 항목 (미실행)

자동 테스트로 확인할 수 없는 화면 항목이다. `python src/app.py` 실행 후 브라우저에서 확인한다.

| ID | 화면 | 확인 내용 | 결과 |
|----|------|-----------|------|
| M-01 | S1 홈 | 단어가 4개 미만이면 학습 시작 버튼 대신 안내가 나온다 | 미확인 |
| M-02 | S2 학습 | 보기 버튼을 누르면 1초 이내에 정답 또는 오답이 표시된다 | 미확인 |
| M-03 | S2 학습 | 키보드 1~4 키로 보기를 고를 수 있다 | 미확인 |
| M-04 | S2 학습 | 오답이면 정답이 표시되고 같은 세션 안에서 다시 나온다 | 미확인 |
| M-05 | S2 학습 | 다음 버튼이 마지막 문제 뒤에 세션 완료 화면으로 이동한다 | 미확인 |
| M-06 | S4 단어 관리 | 등록, 수정, 삭제가 동작하고 삭제 전에 확인 창이 뜬다 | 미확인 |
| M-07 | S4 단어 관리 | 같은 영어 단어를 등록하면 "이미 등록된 단어입니다"가 나온다 | 미확인 |
| M-08 | S5 학습 기록 | 기록이 없으면 "아직 학습 기록이 없습니다"가 나온다 | 미확인 |
| M-09 | 전체 | 앱을 껐다가 다시 켜도 학습 기록과 복습 대상이 유지된다 | 미확인 |
