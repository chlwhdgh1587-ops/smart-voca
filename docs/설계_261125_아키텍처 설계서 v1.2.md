## 1. 개요

- 개인용 객관식 영어 단어 암기 웹 앱이다. 교실 PC에서 로컬로 실행하고, 기말 과제로 학교 서버에도 올린다.
- 2026-11-25부터 두 가지 실행 방식을 함께 지원한다.
  - **로컬 실행**: `python src/app.py` (127.0.0.1:5000, 개발 서버)
  - **서버 실행**: Docker 이미지, `gunicorn`(0.0.0.0:8080), UID 10001, `/data/voca.db`
- 기술 선택과 근거는 결정 기록(ADR-001~004)에 있다. 2026-11-25의 서버 배포 결정은 이 문서 8절에 적는다.

## 2. 구성 요소 (Topology)

**로컬 실행**
```
[브라우저 (교실 PC)]
        │  HTTP (127.0.0.1:5000)
        ▼
[Flask 앱 (python src/app.py)]
        │  sqlite3 (표준 라이브러리)
        ▼
[SQLite 파일 data/smartvoca.db]
```

**서버 실행 (학교 서버)**
```
[브라우저]
        │  HTTPS (학교 서버 앞단)
        ▼
[앞단 nginx]  /2026/voca-<학번>/ 를 떼고 전달, HTML·JS 안의 주소를 다시 붙임
        │  HTTP
        ▼
[컨테이너: gunicorn 1 워커 → Flask 앱, 0.0.0.0:8080, UID 10001, 인터넷 차단]
        │  sqlite3
        ▼
[볼륨 /data/voca.db]
```

| 구성 요소 | 역할 | 비고 |
|-----------|------|------|
| 브라우저 | 화면 표시, 답안 입력 | 별도 설치 없음. 외부 폰트·스크립트 없음 |
| Flask 앱 | 라우팅, 로그인 확인, 학습·시험 로직 호출, HTML 렌더링 | 외부 통신 없음 |
| gunicorn | 운영용 WSGI 서버 | 워커 1개. 세션 키가 프로세스마다 다르므로 워커를 늘리지 않는다 |
| SQLite | 단어, 회원, 학습·시험 기록, 설정 저장 | NFR-002 |
| 앞단 nginx | 주소 접두어 처리 | 서버가 제공. 앱은 `/` 기준으로 만든다 |

외부 서버, 클라우드, 인터넷 연결은 앱이 사용하지 않는다 (NFR-003, ADR-002). 서버 실행 시 컨테이너는 인터넷이 막힌 네트워크에서 돈다.

## 5. HTTP 인터페이스

| 메서드 | 경로 | 요청 | 응답 | 연결 기능 |
|--------|------|------|------|-----------|
| GET | `/` | 없음 | 홈 (등록 단어, 복습 대상, 오늘 진행, 일차) | 전체 |
| GET | `/login` | 없음 | 로그인 화면 | FR-041 |
| POST | `/login` | `username`, `password` | 홈으로 redirect 또는 오류 알림 | FR-041 |
| GET | `/signup` | 없음 | 가입 화면 | FR-041 |
| POST | `/signup` | `username`, `password`, `password_confirm` | 홈으로 redirect 또는 오류 알림 | FR-041 |
| POST | `/logout` | 없음 | 로그인 화면으로 redirect | FR-041 |
| GET | `/study` | 없음 | 학습 화면 (세션 시작 또는 이어서) | FR-02, FR-03 |
| POST | `/api/study/answer` | `word_id`, `selected_meaning` | 채점 결과 JSON. 로그인 없으면 401 | FR-02.3, 02.4, 03.2 |
| GET | `/study/done` | 없음 | 세션 완료 화면 | FR-04.2 |
| GET | `/cards` | 없음 | 오늘의 카드 (읽기 전용) | FR-012 |
| GET | `/words` | `q`(선택) | 단어 목록, 검색 결과, 등록·가져오기 폼 | FR-001~004 |
| POST | `/words` | `english`, `meaning`, `example` | 목록으로 redirect | FR-001 |
| POST | `/words/import` | `csv_file` (multipart, 20MB 이하) | 목록으로 redirect, 가져오기 결과 알림 | FR-003 |
| POST | `/words/<id>/edit` | `english`, `meaning`, `example` | 목록으로 redirect | FR-002 |
| POST | `/words/<id>/delete` | 없음 | 목록으로 redirect | FR-002 |
| GET | `/exam` | 없음 | 시험 설정 화면 (기본값, 이어 풀기 링크) | FR-021~024 |
| POST | `/exam` | `count`, `direction`, `form` | 시험 화면으로 redirect | FR-021~024 |
| GET | `/exam/<id>` | 없음 | 현재 문항 화면 (끝났으면 결과로) | FR-024 |
| POST | `/exam/<id>/answer` | `item_id`, `answer` | 다음 문항 또는 결과로 redirect | FR-025, FR-026 |
| GET | `/exam/<id>/result` | 없음 | 채점 결과 (본인 시험만, 없으면 404) | FR-025 |
| GET | `/report` | 없음 | 학습 기록 (진도, 날짜별, 시험 추이, 자주 틀린 단어) | FR-031~034 |
| GET | `/users` | 없음 | 공개 회원 목록 (일차, 암기 수) | FR-051 |
| GET | `/users/<id>` | 없음 | 공개 회원의 기록 (보기 전용). 비공개는 404 | FR-051~053 |
| GET, POST | `/settings` | 설정 값, `is_public`(체크) | 설정 화면 또는 저장 후 redirect | FR-061, 062, 052 |

- 답안 제출(`/api/study/answer`)만 JSON으로 주고받는다. 나머지는 폼 POST와 redirect를 쓴다.
- 알림은 플래시 메시지다. 오류는 `error` 카테고리로 보내 `!` 접두어로 표시한다.
- 로그인하지 않은 요청은 `require_login`(before_request)이 로그인 화면으로 보낸다. `/api/`는 401을 돌려준다. 로그인 없이 열 수 있는 화면은 `/login`, `/signup`, 정적 파일뿐이다.
- 쓰기 요청은 모두 로그인한 본인 회원 번호(`current_user_id()`)로 처리한다. 다른 회원의 번호를 받는 쓰기 경로는 없다.
- 세션 쿠키는 `HttpOnly`, `SameSite=Lax`다.

**상태 관리**
- 학습 세션의 출제 목록과 재시험 큐는 서버 메모리에 둔다. 회원 번호별 딕셔너리(`_active_sessions`)로 나눈다. 단일 워커 가정이다.
- 학습 결과(연속 정답 수, 복습 대상, 답안)는 답할 때마다 DB에 저장한다.
- 시험 상태(문항, 정답, 내 답)는 전부 DB(`exam_session`, `exam_item`)에 있다. 재시작해도 끝나지 않은 시험을 이어 풀 수 있다.
- 재시작하면 메모리의 학습 세션은 사라진다. 다음 `/study` 접속 때 `finished_at`이 비어 있는 이전 세션을 종료 처리하고 새로 구성한다 (프로세스 설계서 1절).

## 6. 비기능 요구 대응

| NFR | 대응 방식 |
|-----|-----------|
| NFR-001 사용성 | 답안 제출을 JSON으로 처리해 즉시 피드백. 큰 글자와 버튼, 반응형 화면 |
| NFR-002 데이터 보존 | 모든 학습·시험·회원·설정을 SQLite에 저장. 로컬은 `data/smartvoca.db`, 서버는 `/data/voca.db` |
| NFR-003 외부 통신 없음 | 앱은 외부 호출을 하지 않는다. 서버 이미지는 빌드할 때 의존성을 받고 실행 중에는 인터넷을 쓰지 않는다 |
| NFR-004 추적성 | 함수 주석과 테스트 이름에 FR ID를 적는다. 요구사항 명세서의 구현 위치 표와 연결 |
| NFR-005 초기 데이터 | `seed_words.py` 명령행 또는 웹 CSV 가져오기 (UTF-8, 중복 건너뜀) |
| 비밀값 | `SECRET_KEY`(없으면 기동할 때 무작위), `DB_PATH` 환경변수. 코드·이미지·리포에 두지 않음 |
| 보안 (도전) | 비밀번호 해시(werkzeug), 로그인 게이트, 세션 쿠키 `HttpOnly`·`SameSite=Lax`, 다른 회원의 기록은 공개 설정일 때만 보기 전용 |
| 서버 배포 | UID 10001, 쓰기는 `/data`·`/tmp`만, 0.0.0.0:8080, 워커 1개, `--cap-drop ALL` 실행 (CI 점검으로 확인) |

## 7. 실행 방식

**로컬 (교실 PC)**
1. `python -m pip install -r requirements.txt` (최초 1회)
2. `python src/seed_words.py` (기초 단어 100개, 선택)
3. `python src/app.py` 실행 후 `http://127.0.0.1:5000` 접속. 처음에는 가입한다.
4. 테스트: `python -m unittest discover -s tests` (프로젝트 루트에서)

**서버 (학교 서버, Docker)**
1. 리포 루트에서 `docker build .` (R-01)
2. 실행 조건: 포트 8080, `DB_PATH=/data/voca.db`, `SECRET_KEY` 환경변수, `/data` 볼륨
3. 명령 예: `gunicorn --chdir src --bind 0.0.0.0:8080 "app:create_app()"` (Dockerfile CMD)
4. 배포 검증: GitHub Actions 점검 워크플로 (빌드, 실행, 첫 화면, 링크 점검, 재시작, 이미지 크기)
