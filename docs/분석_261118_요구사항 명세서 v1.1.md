## 1. 개요

- **목적**: 기획서의 FR-01~04를 구현 가능한 수준으로 풀어 쓴다.
- **범위**: 개인용 객관식 영어 단어 암기 학습 도구. 사용 환경은 교실.
- **ID 체계**: 기획서의 FR ID를 그대로 사용하고, 하위 요구사항은 `FR-xx.y`로 부여한다. 구현 코드와 테스트는 이 ID와 연결한다 (방법론 §3-1).

## 2. 용어 정의

| 용어 | 정의 |
|------|------|
| 단어 | 영어 단어 1개, 그 뜻 1개, 선택 예문 1개로 구성된 학습 항목 |
| 신규 단어 | 아직 한 번도 신규 블록에서 답하지 않은 단어 |
| 세션 | 한 번의 학습 단위. 객관식 문제를 연속으로 푼다 |
| 블록 | 세션 안의 묶음. 복습 블록을 먼저 풀고 신규 블록을 나중에 푼다 |
| 연속 정답 수 | 같은 단어를 시도할 때 연속으로 맞힌 횟수. 틀리면 0으로 초기화한다 |
| 완벽 암기 | 연속 정답 수가 3 이상이 된 상태 |
| 복습 대상 | 다음 날 복습 세션에서 출제되는 단어. 복습 세션이 끝나면 복습 대상에서 해제된다 |

## 3. 기능 요구사항 (Functional Requirements)

| ID | 기능명 | 상세 설명 | 우선순위 | 관련 BR |
|----|--------|-----------|----------|---------|
| FR-01 | 단어 관리 | 단어장을 관리한다 | 상 | BR-01 |
| FR-01.1 | 단어 등록 | 영어 단어와 뜻을 입력해 저장한다. 예문은 선택 입력 항목이다 | 상 | BR-01 |
| FR-01.2 | 단어 수정 | 등록된 단어의 영어·뜻·예문을 수정한다. 학습 상태는 유지한다 | 중 | BR-01 |
| FR-01.3 | 단어 삭제 | 등록된 단어를 삭제한다. 삭제 전 학습 기록도 함께 삭제됨을 확인받는다 | 중 | BR-01 |
| FR-01.4 | 단어 목록 조회 | 등록된 단어를 영어·뜻·예문과 함께 목록으로 보여준다 | 중 | BR-01 |
| FR-02 | 암기 학습 세션 | 하루 20개 신규 단어를 객관식으로 학습한다 | 상 | BR-01, BR-02 |
| FR-02.1 | 세션 구성 | 당일 세션에 미출제 신규 단어 20개를 등록 순서대로 선정한다. 복습 대상이 있으면 복습 블록을 먼저 구성한다 | 상 | BR-01 |
| FR-02.2 | 객관식 출제 | 단어 1개당 뜻 보기 4개(정답 1, 오답 3)를 제시하고 1개를 고르게 한다. 오답 보기는 다른 등록 단어의 뜻에서 뽑는다. 보기를 만들려면 서로 다른 뜻이 4개 이상 등록되어 있어야 하며, 그 전에는 학습을 시작하지 않는다 (ADR-004) | 상 | BR-01 |
| FR-02.3 | 세션 내 재시험 | 세션 중 틀린 단어는 맞힐 때까지 같은 세션 안에서 다시 출제한다 | 상 | BR-02 |
| FR-02.4 | 완벽 암기 판정 | 단어별 연속 정답 수를 저장하고, 연속 3회 정답이면 완벽 암기로 표시한다. 오답으로 연속 정답 수가 3 미만이 되면 완벽 암기 표시도 해제한다 | 상 | BR-02 |
| FR-03 | 복습 스케줄링 | 다음 날 복습 대상을 산출하고 출제한다 | 상 | BR-03 |
| FR-03.1 | 복습 대상 산출 | 학습 세션에서 출제된 단어 중 맞힌 단어와 틀린 단어 모두를 다음 날 복습 대상으로 저장한다 | 상 | BR-03 |
| FR-03.2 | 복습 출제 | 복습 대상 단어를 다음 날 복습 세션에서 객관식으로 출제하고, FR-02.4 판정 규칙을 동일하게 적용한다. 복습 세션에서는 정답이어도 연속 3회 정답에 도달할 때까지 다시 출제하여, 세션이 끝나면 복습 대상 단어가 모두 완벽 암기 상태가 되게 한다 | 상 | BR-03 |
| FR-03.3 | 복습 대상 해제 | 복습 세션의 모든 단어가 연속 3회 정답에 도달해 세션이 끝나면 복습 대상 전체를 해제한다 | 상 | BR-03 |
| FR-04 | 학습 기록 조회 | 학습 결과를 조회한다 | 중 | BR-01, BR-02 |
| FR-04.1 | 날짜별 학습량 | 날짜별 학습 단어 수를 보여준다 | 중 | BR-01 |
| FR-04.2 | 정답률 | 세션 완료 화면에 세션별 정답률을, 학습 기록 화면에 날짜별 정답률을 보여준다 | 중 | BR-02 |
| FR-04.3 | 완벽 암기 현황 | 완벽 암기 단어 수와 복습 대기 단어 수를 보여준다 | 중 | BR-02, BR-03 |

## 4. 비기능 요구사항 (Non-Functional Requirements)

| ID | 분류 | 요구사항 | 기준 |
|----|------|----------|------|
| NFR-01 | 사용성 | 교실에서 학생이 한 문제를 풀고 결과를 바로 확인할 수 있어야 한다 | 정답·오답 표시가 응답 후 1초 이내 |
| NFR-02 | 데이터 보존 | 학습 기록과 단어 상태는 프로그램을 종료한 뒤에도 유지되어야 한다 | 재실행 후 연속 정답 수와 복습 대상이 그대로 남아 있음 |
| NFR-03 | 개인정보 | 실명, 학번 등 개인 식별 정보를 저장하지 않는다 | 단어 데이터와 학습 기록에 개인 식별 항목 없음 |
| NFR-04 | 추적성 | 구현 코드와 테스트 케이스에 관련 FR ID를 명시한다 | 모든 FR-xx.y에 대응하는 테스트가 1개 이상 있음 |
| NFR-05 | 데이터 초기화 | 초기 단어 데이터는 직접 작성한 토익 수준 영단어 100개 목록(`data/words_public.csv`, 열: 영어·뜻·예문)을 사용한다. 모든 항목에 예문을 포함한다. 외부 자료를 쓰지 않아 이용 조건 문제가 없다 | 목록 파일 100행, 모든 행에 예문, 영단어 중복 없음, 적재 후 등록 단어 수 100개 |

## 5. 수용 기준 (Acceptance Criteria)

주요 기능의 완료 조건을 BDD 형식으로 정의한다. 테스트 정의서의 시나리오 원본이 된다.

**FR-01.1 예문 생략 등록**
- Given: 영어 "approve"와 뜻 "승인하다"만 입력했다
- When: 등록 버튼을 누른다
- Then: 예문 없이 저장되고, 학습 중 이 단어의 예문 영역은 표시되지 않는다

**FR-02.4 완벽 암기 판정**
- Given: 단어 "apple"의 연속 정답 수가 2이다
- When: 학생이 "apple"을 정답으로 고른다
- Then: 연속 정답 수가 3이 되고 "apple"은 완벽 암기 상태가 된다

**FR-02.4 연속 정답 초기화**
- Given: 단어 "apple"의 연속 정답 수가 2이다
- When: 학생이 "apple"을 오답으로 고른다
- Then: 연속 정답 수가 0이 된다

**FR-02.3 세션 내 재시험**
- Given: 세션 중 "apple"을 오답으로 골랐다
- When: 세션의 나머지 문제를 모두 풀었다
- Then: "apple"이 같은 세션 안에서 다시 출제된다

**FR-03.1 복습 대상 산출**
- Given: 오늘 세션에서 "apple"을 맞히고 "banana"를 틀렸다
- When: 다음 날 앱을 실행한다
- Then: "apple"과 "banana"가 복습 대상으로 출제된다

**FR-03.3 복습 대상 해제**
- Given: 다음 날 복습 세션에 "apple"과 "banana"가 복습 대상으로 출제되었다
- When: 두 단어를 모두 연속 3회 정답으로 맞혀 복습 세션이 끝났다
- Then: "apple"과 "banana"가 모두 복습 대상에서 해제되고, 그 다음 날에는 출제되지 않는다

**FR-02.1 세션 구성**
- Given: 등록된 단어 25개가 모두 아직 출제되지 않은 신규 단어이다
- When: 오늘 세션을 시작한다
- Then: 등록 순서대로 20개가 출제된다

**FR-02.2 보기 조건**
- Given: 등록된 단어 5개가 모두 같은 뜻 "사과"이다
- When: 학습을 시작한다
- Then: 학습은 시작되지 않고 "서로 다른 뜻의 단어를 4개 이상 등록해야 학습을 시작할 수 있습니다"가 표시된다

## 7. 확인이 필요한 사항

**확인 필요**
- 없음

**설계 단계로 이월**
- 없음 (기술 스택과 실행 환경은 설계 단계에서 확정되었다).

**확정 사항**
- 정답률 표시 (FR-04.2): 세션 완료 화면은 세션별, 학습 기록 화면은 날짜별로 보여준다. 두 화면 모두 유지한다 (2026-11-18 결정).
- 복습 안내 (FR-03.2): 복습 블록에서 맞혔지만 연속 3회 미만이면 "연속 3번 맞혀야 복습이 끝납니다"를 안내한다 (2026-11-18 결정).
- 초기 단어 데이터: 직접 작성한 토익 수준 영단어 100개 목록, 예문 포함 (NFR-05). 2026-10-28 교체.
- 오답 보기: 4지선다 (정답 1, 오답 3) (FR-02.2)
- 재시험: 틀린 단어는 맞힐 때까지 같은 세션에서 반복 출제 (FR-02.3)
- 완벽 암기 단어의 복습 포함 여부: 포함. 완벽 암기 여부와 관계없이 맞힌 단어와 틀린 단어를 모두 다음 날 복습 대상으로 한다 (FR-03.1)
- 복습 대상 해제 조건: 복습 세션의 모든 단어가 연속 3회 정답에 도달하면 세션이 끝나고 복습 대상 전체를 해제한다 (FR-03.2, FR-03.3)
- 보기 조건: 서로 다른 뜻이 4개 미만이면 학습을 시작하지 않는다 (FR-02.2, ADR-004)

**변경 이력**
- 2026-10-21, 설계 단계 검토: 초기 기본안(복습 세션에서 한 번 맞히면 다음 날부터 해제)은 연속 3회 정답을 달성할 수 없는 결함이 있어 위 조건으로 수정했다. 완벽 암기 단어도 복습에 포함된다는 결정은 그대로 유지한다.
- 2026-10-28: 초기 단어 목록을 "기초 영단어 100개"에서 "토익 수준 영단어 100개, 예문 포함"으로 교체했다 (NFR-05, FR-01.1). 사용자 요청에 따른 변경이다.
- 2026-11-18: 설계 문서 갱신 과정에서 FR-02.2 보기 조건, FR-01.2·01.4 설명(예문), 수용 기준 2건(FR-01.1, FR-02.2)을 추가했다. FR-04.2 정답률 범위는 두 화면 모두 유지로 확정했고, 복습 안내 문구를 확정 사항에 추가했다.
