## 3. 구현 원칙

- 설계 문서의 함수 이름과 파일 이름을 그대로 쓴다. 바꾸면 설계서를 먼저 고친다.
- 모든 파일 상단에 CLAUDE.md의 헤더(작성일, 파일 위치, 목적)를 둔다.
- DB 쓰기는 `with conn:` 트랜잭션 안에서 한다.
- 500줄을 넘는 파일은 나누는 것을 제안한다. 현재 가장 큰 파일은 `study_service.py`로 약 330줄이다.

## 4. 구현 중 설계를 바꾼 내역

| 항목 | 변경 | 근거 |
|------|------|------|
| 복습 해제 규칙 | 복습 블록에서는 연속 3회 정답까지 반복 출제 | 한 번 맞힌 뒤 해제하면 완벽 암기에 도달할 수 없었다 (요구사항 명세서 7장 변경 이력) |
| 학습 시작 조건 | 등록 단어 4개 이상 → 서로 다른 뜻 4개 이상 | 뜻이 같으면 보기 4개를 만들 수 없다 (ADR-004) |
| 세션 상태 | 재시험 큐를 서버 메모리에 보관, 재시작 시 미완료 세션 닫기 | 단일 사용자 기준의 단순한 구조 (아키텍처 설계서 5절) |
