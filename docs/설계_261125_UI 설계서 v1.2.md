## 1. 설계 원칙

- 교실 프로젝터와 학생 PC 화면에서 모두 읽히도록 글자와 버튼을 크게 한다 (NFR-001).
- 정답과 오답은 색과 글자를 함께 표시한다 (색맹 사용자 고려).
- 한 화면에 할 일 하나만 둔다.
- 외부 폰트와 라이브러리를 쓰지 않는다. 색은 CSS 변수로 관리하고, 밝은 화면과 어두운 화면을 시스템 설정에 따라 전환한다.
- 주소는 `/`로 시작하는 경로 또는 상대 경로로 쓴다. 호스트를 쓰지 않는다. 서버에서는 `/2026/voca-<학번>/` 아래에서 열린다 (서버 배포 규칙 R-04).
- 로그인하지 않으면 학습 화면은 열리지 않는다. 로그인 화면이 첫 화면이 된다.

## 3. 화면 흐름

```
S0a 로그인 ──[로그인]──▶ S1 홈
S0b 가입 ────[가입]────▶ S1 홈
S0a ⇄ S0b (서로 이동)

S1 홈 ──[학습 시작]──▶ S2 학습 ──(마지막 문제 다음)──▶ S3 세션 완료 ──[홈으로]──▶ S1
 │
 ├── [오늘의 카드] ──▶ S6 카드
 ├── [시험 보기] ───▶ S7 시험 설정 ──[시작]──▶ S8 문항 ──(마지막 문항 다음)──▶ S9 결과
 │                                            (끊겨도 S7의 "이어서 풀기"로 복귀)
 └── 학습할 것이 없으면 S2 진입 시 "오늘 할 학습이 없습니다" 표시 후 S1로 복귀

로그인하지 않은 상태에서 다른 화면으로 가면 S0a로 보내고 "로그인이 필요합니다." 알림을 보인다.
```

상단 바 메뉴는 로그인 상태에 따라 다르다 (4절).

## 4. 공통 레이아웃

- **상단 바**: 로고 마크 "S"와 "스마트보카". 로그인 상태에서는 메뉴 8개 (학습, 카드, 시험, 단어 관리, 학습 기록, 사용자, 설정)와 오른쪽에 아이디와 "로그아웃" 버튼. 로그아웃 상태에서는 "로그인", "회원 가입" 두 개.
- **본문**: 카드 단위로 묶는다. 제목은 `h1`, 카드 안의 소제목은 `h2`.
- **알림**: 등록, 수정, 삭제, 저장, 로그인 결과와 오류 메시지를 본문 맨 위에 한 줄로 표시한다. 성공은 `✓`, 오류는 `!`로 시작한다 (6절).
- **반응형**: 폭 720px 이하에서는 한 열로 배치한다. 상단 바 메뉴는 줄바꿈한다.
- **로그아웃은 POST 버튼**으로 한다. 링크로 만들지 않는다 (다른 사이트에서 로그아웃시키는 것을 막기 위해).

## 5. 화면별 구성

### S0a 로그인, S0b 회원 가입

```
┌──────────────────────────────────────┐
│  로그인                                │
│  아이디     [______________]            │
│  비밀번호   [______________]            │
│              [ 로그인 ]                 │
│  계정이 없으면 회원 가입을 하세요.         │
└──────────────────────────────────────┘
```

- 가입: 아이디(영문 소문자, 숫자, 밑줄, 3~20자), 비밀번호(8자 이상), 비밀번호 확인.
- 아이디나 비밀번호가 틀리면 "아이디 또는 비밀번호가 맞지 않습니다."를 표시한다. 어느 쪽이 틀렸는지는 알려 주지 않는다.
- 가입 실패 사유(짧은 아이디, 확인 불일치, 이미 사용 중인 아이디)는 알림으로 표시한다.
- 비밀번호 입력 칸은 `type="password"`로 둔다.

### S1 홈

```
┌──────────────────────────────────────┐
│  오늘도 한 단계씩, TOEIC 단어           │
│  오늘의 학습 · 3일차                    │
│          [ 학습 시작 → ]               │
│  오늘의 카드 · 시험 보기                 │
│                                      │
│  [등록 단어 100 개] [복습 대상 12 개]     │
│  [오늘 신규 진행 0 / 20  ▭▭▭▭▭▭▭▭]      │
└──────────────────────────────────────┘
```

- 제목에 현재 일차를 붙인다 (VOCA-FR-011).
- 서로 다른 뜻의 단어가 4개 미만이면 "학습 시작" 버튼 대신 "단어 등록하기 →"(S4)와 안내 문구를 표시한다 (ADR-004).
- 통계 3개: 등록 단어, 복습 대상(오늘 복습 후보 수), 오늘 신규 진행(`하루 목표 - 남은 목표` / 하루 목표, 진행 막대).
- 하루 목표는 설정값을 따른다 (기본 20).

### S2 학습

```
┌──────────────────────────────────────┐
│  [신규]                        1 / 20 │
│  ▭▭▭▭▭▭▭▭▭▭▭▭▭▭▭▭▭▭▭▭▭▭▭▭▭▭▭▭▭▭▭▭▭▭      │
│                                      │
│                approve               │
│          알맞은 뜻을 고르세요             │
│  [1] 승인하다                          │
│  [2] 사과                              │
│  [3] 바나나                            │
│  [4] 포도                              │
│                                      │
│  (결과 문구)                           │
│  (예문, 학습 단어 강조)                  │
│                         [ 다음 → ]     │
└──────────────────────────────────────┘
```

- 블록 칩: `신규` 또는 `복습`. 복습 칩은 다른 색으로 구분한다.
- 진행 표시: 블록 안에서 처음 나온 단어의 순서 `n / N`과 진행 막대. 틀린 단어의 재출제는 순서에 포함하지 않는다 (FR-02.3).
- 보기는 4개. 버튼을 누르거나 숫자 키 1~4로 바로 제출한다. 제출 후 보기는 모두 비활성화한다.
- 결과 표시 (제출 후 1초 이내, NFR-001):
  - 정답: "정답입니다!" 문구, 초록 배경. 고른 보기와 정답 보기를 초록으로 표시한다.
    - 복습 블록에서 맞혔지만 연속 정답이 3회 미만이면 문구 뒤에 "이 단어는 연속 3번 맞혀야 복습이 끝납니다"를 덧붙인다.
    - 복습 블록의 모든 단어가 연속 3회 정답에 도달해 블록이 끝난 마지막 답에서만 "정답입니다! 복습이 끝났습니다"로 표시한다.
  - 오답: `오답입니다. 정답은 "뜻" — 이 세션 안에서 다시 나옵니다` 문구, 빨간 배경. 고른 보기는 빨강, 정답 보기는 초록.
- 예문: 답을 낸 뒤 예문이 있으면 표시한다. 학습 단어는 `mark`로 강조한다. 예문이 없으면 영역을 숨긴다.
- 다음: "다음 →" 버튼 또는 Enter 키. 세션의 마지막 문제였으면 S3로 이동한다.
- 키보드: 답하기 전에는 1~4, 답한 뒤에는 Enter로 다음 문제.

### S3 세션 완료

- 방금 끝난 세션이 있을 때만 보인다. 그 밖에 직접 접근하면 S1로 보낸다.
- 표시: 학습 단어 수, 정답률(소수 첫째 자리 `%`), 완벽 암기 수, 복습 대기 수.

### S4 단어 관리

```
┌──────────────────────────────────────┐
│  새 단어 등록                           │
│  영어 [________] 뜻 [________]           │
│  예문 [__________________] [ 추가 ]      │
│                                      │
│  CSV 가져오기                           │
│  첫 줄 english,meaning (예문 열은 선택)   │
│  [파일 선택] [ 가져오기 ]                 │
│                                      │
│  검색 [__________] [ 검색 ] [ 전체 보기 ]   │
│  총 100개 (검색 결과 n개)                │
│  영어      뜻       예문         [저장] [삭제] │
│  ...                                   │
└──────────────────────────────────────┘
```

- 영어와 뜻은 필수, 예문은 선택이다.
- 영어는 저장 시 앞뒤 공백을 지우고 소문자로 바꾼다. 중복이면 "이미 등록된 단어입니다."를 표시하고 저장하지 않는다.
- 수정: 별도 화면이 없다. 목록의 행 안에서 값을 고치고 "저장"을 누른다. 성공하면 "단어를 수정했습니다."를 표시한다.
- 삭제: 브라우저 확인 창을 띄운다. 문구는 "단어를 삭제하면 모든 회원의 이 단어 학습 기록도 함께 삭제됩니다. 계속할까요?"이다. 단어장은 모든 회원이 함께 쓰므로 삭제가 모든 회원에게 영향을 준다는 점을 적는다 (명세서 4장 한계).
- 검색: 영단어 또는 뜻에 포함된 단어를 찾는다. 대소문자는 무시한다. 결과가 없으면 "검색 결과가 없습니다."를 표시한다.
- CSV 가져오기: UTF-8 파일만 받는다. 결과는 알림 한 줄로 "가져오기 완료: 추가 n개, 중복 건너뜀 n개, 잘못된 행 n개"를 표시한다. 20MB를 넘으면 거절한다.
- 목록이 비어 있으면 "등록된 단어가 없습니다."를 표시한다.

### S5 학습 기록

```
┌──────────────────────────────────────┐
│  홍길동 님의 학습 기록 (본인이면 "학습 기록")  │
│  [현재 3일차] [암기 48 / 100 ▭▭▭▭] [복습 대기 32 개] │
│                                      │
│  날짜      일차  학습 단어  문제 수  정답률    │
│  2026-11-25  3     20       20     85.0 %   │
│                                      │
│  시험 성적 추이                          │
│  날짜   회차  형식    방향    점수    정답률    │
│  날짜별 정답률 표                         │
│                                      │
│  자주 틀리는 단어 (상위 10개)              │
│  영어  뜻  틀린 횟수  정답률                 │
│          [ 홈으로 ]                    │
└──────────────────────────────────────┘
```

- 진도: 현재 일차, 암기한 단어(연속 3회 정답) / 전체, 백분율 막대.
- 날짜별 표: 최근순. 일차 열은 신규 학습이 있었던 날짜만 번호가 있고 나머지는 `-`.
- 시험 추이: 회차별 표(형식, 방향 한글 표기, 점수, 정답률)와 날짜별 정답률 표. 시험이 없으면 "끝낸 시험이 없습니다. 시험 보기" 링크를 보인다.
- 자주 틀리는 단어: 암기와 시험 틀린 횟수를 합친 상위 10개. 없으면 "틀린 단어가 아직 없습니다."
- 정답률은 소수 첫째 자리 `%`. 기록이 없는 값은 `-`.
- 기록이 없으면 "아직 학습 기록이 없습니다. 첫 학습을 시작해 보세요."를 표시한다.

### S6 오늘의 카드

- 영단어를 크게 보여 준다. "뜻 보기" 버튼을 누르면 뜻과 예문(있으면)이 나온다. "다음 →"으로 한 장씩 넘긴다. 마지막 장 다음은 처음으로 돌아간다.
- 카드 목록은 오늘 먼저 공부한 신규 단어가 앞에 오고, 목표 수까지 다음 신규 단어로 채운다.
- 학습 기록을 남기지 않는다. 화면 아래에 "카드 암기는 기록에 남지 않습니다. 실제 학습은 학습에서 합니다."를 표시한다.
- 단어가 없으면 "오늘 암기할 단어가 없습니다. 단어를 등록하거나 학습 설정을 확인하세요."를 표시한다.

### S7 시험 설정

- 문제 수(설정 기본값 선택: 5, 10, 20문제), 출제 방향(영어 → 뜻, 뜻 → 영어, 섞기), 출제 형식(4지선다, 단답형, OX, 섞기)을 고른다. 기본값은 설정 화면의 값이다.
- 끝나지 않은 시험이 있으면 상단에 "끝나지 않은 시험이 있습니다. 이어서 풀기 →"를 보인다.
- 단어가 부족하면 시작하지 않고 알림으로 "시험을 보려면 단어가 n개 이상 있어야 합니다."를 표시한다.
- 안내 문구: 시험 본 적 없는 단어, 자주 틀린 단어, 오래 전에 본 단어가 더 자주 나온다.

### S8 시험 문항

```
┌──────────────────────────────────────┐
│  3 / 10 · 영어 → 뜻                     │
│  다음 영단어의 뜻은?                     │
│                approve                │
│  [승인하다] [사과] [바나나] [포도]          │
└──────────────────────────────────────┘
```

- 4지선다: 보기 4개를 버튼으로 보인다. 누르면 바로 채점하고 다음 문항으로 넘어간다.
- 단답형: 입력 칸과 "확인" 버튼. 대소문자와 앞뒤 공백은 무시한다.
- OX: 제시된 뜻(또는 영단어) 한 줄을 보이고 "O"와 "X" 버튼. 제시된 뜻이 맞으면 O다.
- 채점 결과는 알림 한 줄로 표시한다. 맞으면 "정답입니다.", 틀리면 "틀렸습니다. 정답은 … 입니다."(빨간색, `!`).
- 진행 표시: `n / 전체`. 방향과 형식은 문항마다 다를 수 있으므로 문제 문구를 방향에 맞춘다 ("다음 영단어의 뜻은?" 또는 "다음 뜻에 맞는 영단어는?").
- 새로고침이나 재접속 후에도 같은 문항에서 이어 풀 수 있다.

### S9 시험 결과

- 점수(정답 / 전체)와 정답률을 큰 글자로 보인다.
- 틀린 문항을 표로 보인다: 문제, 내 답(무응답이면 "(무응답)"), 정답.
- 틀린 문항이 없으면 "모두 맞혔습니다."를 표시한다.
- 버튼: "다시 시험 보기"(S7), "학습 기록 보기"(S5).

### S10 다른 회원의 기록 목록

- 공개로 설정한 회원만 나온다. 본인이 공개했으면 "(나)"를 붙인다.
- 열: 아이디, 현재 일차, 암기한 단어 / 전체, 보기 링크.
- 없으면 "공개한 회원이 아직 없습니다. 설정에서 공개할 수 있습니다."를 표시한다.
- 페이지 맨 위에 "다른 회원의 학습 기록입니다. 공개한 회원의 기록만 보입니다. 보기만 할 수 있습니다."를 표시한다.

### S11 공개 회원의 기록 (보기 전용)

- S5와 같은 구성이고 제목만 "아이디 님의 학습 기록"이다.
- 맨 위에 "다른 회원의 기록입니다. 보기만 할 수 있습니다."를 표시한다.
- 입력 폼과 버튼 (삭제, 수정 등)은 없다. 본인 번호로 가면 S5로 보낸다.
- 비공개 회원이면 404 화면을 보인다.

### S12 설정

- 학습 설정: 하루 신규 단어 수(5~50, 숫자 입력), 복습 비율(50%, 100%).
- 시험 설정: 문제 수(5, 10, 20), 출제 방향, 출제 형식.
- 공개 설정: "내 학습 기록을 다른 회원에게 공개합니다 (보기만 가능)" 체크박스.
- 한 번의 "설정 저장" 버튼으로 모두 저장한다. 저장하면 "설정을 저장했습니다."를 표시한다.
- 잘못된 값은 저장하지 않고 "하루 학습량은 5~50 사이로 입력하세요." 같은 알림을 표시한다.

## 6. 표시 규칙

| 항목 | 규칙 |
|------|------|
| 글자 크기 | 영어 단어는 가장 크게, 보기는 본문보다 크게 |
| 정답 표시 | 글자와 배경색을 함께 쓴다. 정답은 초록, 오답은 빨강 |
| 숫자 | 정답률은 소수 첫째 자리 `%`. 해당 없음은 `-` |
| 날짜 | `YYYY-MM-DD` |
| 알림 | 본문 맨 위에 한 줄. 성공은 `✓`, 오류는 `!` 접두어 |
| 방향 표기 | 영어 → 뜻, 뜻 → 영어, 섞기 |
| 형식 표기 | 4지선다, 단답형, OX, 섞기 |
| 테마 | 시스템 설정에 따라 밝은 화면과 어두운 화면 자동 전환 |
| 보기 전용 | 다른 회원의 기록 화면에는 입력 폼과 쓰기 버튼을 두지 않는다 |

**결정 사항**

1. (2026-11-18) 정답률 자릿수: 소수 첫째 자리로 통일.
2. (2026-11-18) 복습 재출제 안내: 연속 3회 미만이면 "이 단어는 연속 3번 맞혀야 복습이 끝납니다"를 덧붙인다.
3. (2026-11-18) 알림 구분: 성공은 `✓`, 오류는 `!`로 시작한다.
4. (2026-11-25) 카드 암기는 학습 기록을 남기지 않는다. 카드에서 본 것만으로 복습 대상이 되지 않는다.
5. (2026-11-25) 시험은 문항마다 바로 채점하고, 결과 화면은 끝난 뒤에만 보인다. 중간에 끊겨도 DB에 남은 문항부터 이어 푼다.
