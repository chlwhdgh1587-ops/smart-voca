## 1. 개요

- **목적**: 스마트보카 개발 전에 현재 상황과 제약을 확인하고, 요구사항 명세서(`분석_261021_요구사항 명세서 v1.0.md`)의 근거를 남긴다.
- **범위**: 개인용 객관식 영어 단어 암기 학습 도구. 사용 환경은 교실.
- **참고 문서**: 기획서(`기획_261021_스마트보카 v1.0.md`), 요구사항 명세서(`분석_261021_요구사항 명세서 v1.0.md`)

| 항목 | 현황 |
|------|------|

| 소스 코드 | 없음 (`src/` 미생성) |

## 3. 기존 학습 프로세스

| 항목 | 현황 |
|------|------|
| 단어 학습 방식 | 객관식 (사용자 확정) |
| 단어 등록 방식 | 초기 데이터는 직접 작성한 기초 영단어 100개 목록 사용으로 확정 (NFR-05) |
| 복습 방식 | 같은 세션 재시험 + 다음 날 복습 (사용자 확정) |
| 암기 완료 판정 | 연속 3회 정답 (사용자 확정) |

현재 학생들이 단어를 어떻게 외우는지에 대한 조사는 하지 않았다. 과제 범위에서 사용자 조사는 제외한다.

## 5. 문제점 및 개선 기회

기존 시스템이 없으므로 아래 항목은 현재 상태 조사가 아니라, 목표 달성을 가로막을 것으로 예상되는 문제다.

| 문제 | 설명 | 대응 요구사항 |
|------|------|----------------|
| 하루 학습량 관리 | 하루 20개 목표를 기록하고 맞추는 수단이 없음 | FR-02.1, FR-04.1 |
| 암기 상태 판정 | 단어별 암기 여부를 기록하는 수단이 없음 | FR-02.4, FR-04.3 |
| 복습 누락 | 다음 날 어떤 단어를 복습할지 관리하기 어려움 | FR-03.1, FR-03.2 |
