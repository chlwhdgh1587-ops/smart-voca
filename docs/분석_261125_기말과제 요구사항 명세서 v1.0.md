- **구현**: 코드가 있고 아래 검증 방법으로 확인됨

## 4. 알려진 한계 (제출 전 공지용)

- **단어장은 공용**: 모든 회원이 같은 단어를 보고 고칠 수 있다. 이력만 계정별이다.
- **기존 기록 귀속**: DB 이관 시 기존 학습 기록은 **첫 번째 가입 계정**(회원 번호 1)에 붙는다. 서버 DB는 새로 만들어지므로 해당 없음.
- **세션 키 재시작**: `SECRET_KEY`를 주지 않으면 서버를 재시작할 때마다 로그인이 풀린다. 서버에서는 환경변수로 고정하는 것을 권장한다.
- **단일 워커**: gunicorn 워커 1개로 실행해야 한다 (진행 중인 학습과 시험 상태는 프로세스 메모리에 있다. 학습 세션은 재시작하면 닫히고, 시험은 DB에 남아 이어 풀 수 있다).
- **CSRF**: 세션 쿠키를 `SameSite=Lax`로 두어 다른 사이트에서 오는 POST를 막는다. 별도 토큰은 없다.
- **로그인 시도 제한 없음**: 교실 실습 범위로 한정한다.
- **그래프 없음**: 시험 추이는 표로만 보여 준다.
