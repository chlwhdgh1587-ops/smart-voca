## ADR-001 기술 스택: Python 3.11 + Flask + SQLite

**배경**
- 개인용 객관식 학습 앱이며, 교실 PC에서 실행된다.
- 학습 상태를 재실행 후에도 유지해야 한다 (NFR-02).
- 과제 기간은 1개월이며, 학생이 구조를 설명할 수 있어야 한다.

**대안**
| 대안 | 장점 | 단점 |
|------|------|------|
| Python + Tkinter (데스크톱) | 추가 설치 없음 | 화면 구성이 불편하고 UI 코드가 길어짐 |
| Python + Streamlit | 화면 작성이 빠름 | 입력 때마다 스크립트 재실행, 세부 제어가 어려움 |
| 순수 HTML/JS + localStorage | 서버 불필요 | 저장소가 브라우저에 묶임, 로직이 JS에 몰림 |
| **Python + Flask + SQLite** | 라우팅과 템플릿이 명확, DB가 파일 하나 | Flask 설치 필요 |

**결정**: Python 3.11, Flask(3.x 고정), 표준 라이브러리 sqlite3를 사용한다.

**근거**
- 브라우저 UI라서 교실에서 사용하기 쉽다.
- SQLite 파일 하나로 학습 상태가 보존된다 (NFR-02).
- 외부 서비스가 필요 없어 개인정보 제약을 지키기 쉽다 (NFR-03).
- 라우트, 서비스, DB 계층을 나누기 쉬워 설명과 테스트가 간단하다.

**영향**
- 구현 전에 Python 3.11과 Flask 설치가 필요하다. 설치는 CLAUDE.md의 승인 필요 작업이다.

## ADR-002 실행 환경: 교실 PC 로컬 실행

**배경**
- 사용 환경은 교실이다 (사용자 확정).
- 개인 학습 기록을 외부에 두지 않아야 한다.

**대안**
| 대안 | 문제 |
|------|------|
| 학교 서버 배포 | 서버 운영 권한과 네트워크가 필요하며, 개인 기록이 외부에 놓임 |
| 클라우드 배포 | 비용과 계정 관리가 필요하고, 과제 범위를 넘어섬 |
| **로컬 실행 (127.0.0.1)** | 설치와 운영이 단순 |

**결정**: `python src/app.py`로 실행하고 `http://127.0.0.1:5000`에 접속한다. 바인딩은 127.0.0.1로 제한한다.

**근거**: 외부 노출이 없고 네트워크가 없어도 동작한다. 과제 범위에 맞는다.

**영향**: 여러 기기에서 같은 기록을 볼 수 없다. 개인용 단일 사용자 기준(기획서 7장)과 일치한다.

## ADR-003 학습 상태 저장: DB 컬럼으로 보관

**배경**
- 연속 정답 수, 복습 대상, 최초 학습일은 재실행 후에도 유지되어야 한다 (NFR-02).

**대안**
| 대안 | 문제 |
|------|------|
| 메모리 보관 | 앱을 끄면 사라짐 |
| JSON 파일 보관 | 동시 쓰기와 조회 조건 처리가 번거로움 |
| **SQLite 테이블 보관** | 조건 조회(예: 복습 대상)가 쉬움 |

**결정**: 단어 테이블, 단어 상태 테이블, 세션 테이블, 답안 테이블로 나눠 저장한다 (데이터 설계서 참고).

**근거**: 복습 대상 조회와 날짜별 집계를 SQL 하나로 처리할 수 있다.

**영향**: 완벽 암기 여부는 별도 컬럼이 아니라 연속 정답 수에서 계산한다. 상태가 한 곳에서만 관리되어 불일치가 생기지 않는다.

## ADR-004 오답 보기 선정: 등록 단어에서 무작위 3개

**배경**
- 4지선다의 오답 보기를 어떻게 고를지 정해야 한다 (FR-02.2).

**대안**
| 대안 | 문제 |
|------|------|
| 난이도 기반 선정 | 난이도 정보가 없어 구현 근거가 없음 |
| 같은 품사 단어에서 선정 | 품사 정보가 없어 구현 불가 |
| **등록 단어의 뜻에서 무작위 3개 (정답과 뜻이 같은 것은 제외)** | 단순하고 데이터만 있으면 동작 |

**결정**: 정답을 제외한 등록 단어 중 뜻이 중복되지 않는 3개를 무작위로 고른다. 서로 다른 뜻이 4개 미만이면 학습을 시작하지 않고 단어 등록을 안내한다.

**근거**: 요구사항 명세서 FR-02.2의 범위 안에서 가장 단순하다.

**영향**: 단어 수가 4개 미만이면 학습을 시작할 수 없다. 화면에 안내를 표시한다 (UI 설계서).
