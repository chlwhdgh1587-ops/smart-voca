## 3. 화면 리디자인

- **요청**: UI가 단조롭고 초라함. 최신 트렌드에 맞게 재디자인
- **처리**
  - `src/static/style.css` 전면 교체: CSS 변수, 카드형 레이아웃, 그라데이션 강조, 다크 모드(`prefers-color-scheme`), 반응형(720px 이하). 외부 폰트·라이브러리 없음
  - `base.html`: 상단 바 재구성, 로고 마크, 알림을 알약형으로 표시
  - `home.html`: 히어로 카드, 통계 3개(등록 단어, 복습 대상, 오늘 신규 진행 막대)
  - `study.html`: 블록 칩(신규/복습), 진행 막대, 키캡(1~4) 보기, 답 후 예문 표시(학습 단어 강조), Enter로 다음
  - `words.html`: 등록 카드 + 한 줄 수정·삭제 목록 (수정·삭제 폼은 `form` 속성으로 연결)
  - `report.html`, `done.html`: 통계 타일과 완료 화면
  - `study_service.py`: 문제와 답안 응답에 `example` 추가, 홈 상태에 `daily_target` 추가
- **발견·수정한 문제**
  - `.button`의 `display`가 `hidden` 속성을 덮어써 "다음" 버튼이 답하기 전부터 보임 → `[hidden] { display: none !important; }` 추가
  - "추가" 버튼 글자 줄바꿈 → `white-space: nowrap`
  - 다크 모드에서 히어로 버튼 글자 대비 부족 → 글자색 고정
