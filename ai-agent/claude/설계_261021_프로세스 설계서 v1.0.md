**작성일**: 2026-10-21
**버전**: v1.0 (초안)
**설명**: 학습 세션의 구성, 출제, 답안 처리, 복습 해제, 기록 집계 절차를 정의한 프로세스 설계서

> 용어와 판정 기준은 요구사항 명세서 2장과 데이터 설계서 3장을 따른다. 함수 이름은 아키텍처 설계서 4장을 따른다.

## 1. 학습 세션 구성 (FR-02.1, FR-03.2)

세션은 날짜 `D`의 학습 1회이며, 복습 블록과 신규 블록으로 구성된다. 복습 블록을 먼저 출제한다.

**진행 중 세션 정리**
- 세션 구성 전에 `finished_at`이 비어 있는 이전 세션을 찾아 현재 시각으로 `finished_at`을 채운다. 재시작으로 중단된 세션을 닫는 절차다.
- 이 정리는 DB 기록만 닫고 복습 대상은 건드리지 않는다. 미완료 복습 단어는 4절 3항에 따라 다음 구성에서 다시 대상이 된다.

**절차 (`resume_or_start_session`, `_build_blocks`)**

1. 날짜 `D`를 로컬 시간으로 구한다.
2. 복습 블록 대상을 정한다: `in_review = 1` AND `last_studied_on < D` (또는 NULL)인 단어를 등록 순서(`id` 오름차순)로 모은다.
3. 오늘 신규 학습 수를 센다 (데이터 설계서 3장). 남은 신규 목표는 `20 - 오늘 신규 학습 수`이며 0 미만이면 0으로 한다.
4. 신규 블록 대상을 정한다: `first_studied_on IS NULL`인 단어를 등록 순서로 모아 앞에서부터 남은 신규 목표만큼 고른다.
5. 서로 다른 뜻이 4개 미만이면 세션을 시작하지 않고 단어 등록 화면을 안내한다 (ADR-004).
6. `study_session` 행을 만든다. `new_target`에 남은 신규 목표를 기록한다.

**예외**
- 신규 대상이 0개이면 신규 블록은 건너뛴다.
- 복습 대상과 신규 대상이 모두 0개이면 "오늘 할 학습이 없습니다"를 표시한다.

## 2. 문제 출제 (FR-02.2)

**절차 (`_make_question`, `_pick_distractors`)**

1. 대상 단어 `W`를 하나 정한다.
2. 정답 보기는 `W.meaning`이다.
3. 오답 후보는 `W`를 제외한 등록 단어 중 뜻이 `W.meaning`과 같지 않은 단어의 뜻이다.
4. 오답 후보에서 뜻이 서로 중복되지 않게 3개를 무작위로 고른다.
5. 정답과 오답 3개를 무작위 순서로 섞어 4개 보기를 만든다.

## 3. 답안 처리 (FR-02.3, FR-02.4)

**절차 (`submit_answer`, `_record_attempt`)**

1. 학생이 보기를 고르면 정답 여부를 `selected_meaning = W.meaning`으로 판정한다.
2. `attempt` 행을 추가한다 (`block`은 현재 블록).
3. 연속 정답 수를 갱신한다: 정답이면 +1, 오답이면 0.
4. `last_studied_on = D`로 갱신한다.
5. 신규 블록에서 처음 답한 단어라면 `first_studied_on = D`로 설정한다.
6. 답한 단어는 `in_review = 1`로 설정한다. 다음 날 복습 대상이 된다 (FR-03.1). 같은 날 복습 블록 대상에서는 `last_studied_on < D` 조건으로 제외된다.
7. 응답에 `{correct, correct_meaning}`을 담아 돌려주고, 화면이 1초 이내에 정답 또는 오답을 표시한다 (NFR-01).

**재시험 (FR-02.3)**
- 오답이면 그 단어를 현재 블록 큐의 끝에 다시 넣는다 (신규 블록과 복습 블록 공통).
- 신규 블록: 정답이면 큐에서 뺀다. 즉 정답이 될 때까지 반복한다.
- 복습 블록: 정답이어도 연속 정답 수가 3에 도달하기 전까지는 큐 끝에 다시 넣는다. 블록이 끝나면 복습 대상 단어는 모두 완벽 암기 상태가 된다 (FR-03.2). 이 규칙 덕분에 완벽 암기를 한 세션 안에서 판정할 수 있고, 4절의 복습 해제와 모순되지 않는다.
- 재출제 시에도 3절의 1~7을 그대로 적용한다. 즉 재시험 답안도 `attempt`로 기록되고 연속 정답 수에 반영된다.

**완벽 암기 (FR-02.4)**
- 연속 정답 수가 3 이상이면 완벽 암기 상태다. 별도 저장 없이 계산한다.
- 오답으로 연속 정답 수가 3 미만이 되면 완벽 암기 상태도 자동으로 해제된다.

## 4. 블록 종료와 복습 해제 (FR-03.3)

**복습 블록 종료**
1. 블록의 큐가 비면 블록 완료로 본다. 복습 블록에서는 모든 단어가 연속 3회 정답에 도달해야 큐가 빈다 (3절).
2. 완료되면 그 목록 단어의 `in_review`를 0으로 설정한다. 다음 날 복습 대상에서 빠진다.
3. 블록이 완료되지 않고 앱을 종료하면 해제하지 않는다. 답한 단어는 `last_studied_on = D`라서 같은 날 재시작 때 대상에서 제외되고, 그 단어의 `in_review`는 1로 남아 다음 날 다시 복습 대상이 된다.

**신규 블록 종료**
- 신규 블록의 단어는 `in_review = 1`이 된 상태로 둔다. 다음 날 복습 블록에 나온다.
- 세션 종료 시 `study_session.finished_at`을 기록한다.

## 5. 기록 집계 (FR-04)

**절차 (`daily_summary`, `mastery_summary`)**

1. 날짜별 학습 단어 수: 날짜별 `block = 'new'`인 서로 다른 `word_id` 수 (FR-04.1).
2. 세션별 정답률: 세션의 `is_correct` 합 ÷ 전체 attempt 수 (FR-04.2).
3. 완벽 암기 단어 수: `consecutive_correct >= 3`인 단어 수 (FR-04.3).
4. 복습 대기 단어 수: `in_review = 1`인 단어 수 (FR-04.3).
5. 정답률은 소수 첫째 자리까지 %로 표시한다. attempt가 0이면 "기록 없음"으로 표시한다.

## 6. 단어 관리 (FR-01)

| 절차 | 규칙 |
|------|------|
| 등록 (`add_word`) | 영어를 소문자와 공백 제거로 정규화한다. 중복이면 등록을 거부하고 메시지를 표시한다. 등록과 동시에 `word_state`를 만든다 |
| 수정 (`update_word`) | 영어를 변경할 때 중복 검사를 한다. 학습 상태는 유지된다 |
| 삭제 (`delete_word`) | 삭제 전에 확인 화면을 띄운다. 삭제하면 관련 상태와 답안 기록도 함께 삭제된다 (데이터 설계서 4장 1항) |
| 목록 (`list_words`) | `id` 오름차순으로 보여준다 |

## 7. 상태 전이 요약

| 상태 | 들어가는 조건 | 나가는 조건 |
|------|----------------|-------------|
| 신규 | 등록 | 신규 블록에서 처음 답함 |
| 복습 대상 (`in_review = 1`) | 답한 날 이후 | 복습 블록 완료 시 해제 |
| 완벽 암기 (연속 3 이상) | 연속 정답 3회 | 오답으로 연속 수가 3 미만 |
