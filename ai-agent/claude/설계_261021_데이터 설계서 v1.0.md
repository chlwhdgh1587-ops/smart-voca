# 스마트보카 데이터 설계서

**파일 위치**: `ai-agent/claude/설계_261021_데이터 설계서 v1.0.md`
**작성일**: 2026-10-21
**버전**: v1.0 (초안)
**설명**: 스마트보카의 SQLite 테이블, 컬럼, 제약, 상태 계산 규칙을 정의한 데이터 설계서

> 저장소: SQLite (`data/smartvoca.db`). 날짜는 로컬 시간 기준 `YYYY-MM-DD` 문자열로 저장한다. 시각은 ISO 8601 문자열로 저장한다.

---

## 1. 테이블 개요

| 테이블 | 역할 | 관계 |
|--------|------|------|
| `word` | 단어와 뜻 | 1 : 1 `word_state` |
| `word_state` | 단어별 학습 상태 | `word`의 상태 |
| `study_session` | 한 번의 학습 세션 | 1 : N `attempt` |
| `attempt` | 문제별 답안 기록 | `study_session`, `word`에 연결 |

---

## 2. 테이블 정의

### 2.1 word

| 컬럼 | 타입 | 제약 | 설명 |
|------|------|------|------|
| id | INTEGER | PK, 자동 증가 | 등록 순서를 나타낸다. 신규 선정 순서에 쓰인다 (FR-02.1) |
| english | TEXT | NOT NULL, UNIQUE | 영어 단어. 저장 시 앞뒤 공백을 제거하고 소문자로 정규화한다 |
| meaning | TEXT | NOT NULL | 뜻 |
| example | TEXT | NULL 허용 | 예문 (선택 입력, FR-01.1) |
| created_at | TEXT | NOT NULL | 등록 시각 |

### 2.2 word_state

| 컬럼 | 타입 | 제약 | 설명 |
|------|------|------|------|
| word_id | INTEGER | PK, FK → word.id, ON DELETE CASCADE | 단어 식별자 |
| consecutive_correct | INTEGER | NOT NULL, DEFAULT 0 | 연속 정답 수 (FR-02.4) |
| first_studied_on | TEXT | NULL 허용 | 처음 출제된 날짜. NULL이면 신규 단어 (FR-02.1) |
| last_studied_on | TEXT | NULL 허용 | 마지막으로 답한 날짜 |
| in_review | INTEGER | NOT NULL, DEFAULT 0 | 복습 대상 여부. 1이면 복습 대상 (FR-03.1) |

### 2.3 study_session

| 컬럼 | 타입 | 제약 | 설명 |
|------|------|------|------|
| id | INTEGER | PK, 자동 증가 | 세션 식별자 |
| session_date | TEXT | NOT NULL | 세션 날짜 |
| started_at | TEXT | NOT NULL | 시작 시각 |
| finished_at | TEXT | NULL 허용 | 종료 시각. NULL이면 미완료 |
| new_target | INTEGER | NOT NULL | 이 세션의 신규 목표 수 (20 이하) |

### 2.4 attempt

| 컬럼 | 타입 | 제약 | 설명 |
|------|------|------|------|
| id | INTEGER | PK, 자동 증가 | 답안 식별자 |
| session_id | INTEGER | NOT NULL, FK → study_session.id, ON DELETE CASCADE | 소속 세션 |
| word_id | INTEGER | NOT NULL, FK → word.id, ON DELETE CASCADE | 출제 단어 |
| block | TEXT | NOT NULL, CHECK IN ('new', 'review') | 신규 블록 또는 복습 블록 |
| selected_meaning | TEXT | NOT NULL | 학생이 고른 보기 |
| is_correct | INTEGER | NOT NULL, CHECK IN (0, 1) | 정답 여부 |
| attempted_at | TEXT | NOT NULL | 답한 시각 |

## 3. 파생 값 (저장하지 않고 계산)

| 값 | 계산 | 사용처 |
|----|------|--------|
| 신규 단어 | `word_state.first_studied_on IS NULL` | FR-02.1 |
| 완벽 암기 | `word_state.consecutive_correct >= 3` | FR-02.4, FR-04.3 |
| 복습 대기 수 | `in_review = 1`인 단어 수 | FR-04.3 |
| 오늘 신규 학습 수 | 오늘 `block = 'new'`인 attempt의 서로 다른 `word_id` 수 | FR-02.1 (남은 목표 계산) |
| 날짜별 학습 단어 수 | 날짜별 `block = 'new'`인 서로 다른 `word_id` 수 | FR-04.1 |
| 세션 정답률 | 세션의 `is_correct` 합 ÷ 전체 attempt 수 | FR-04.2 |

---

## 4. 제약과 규칙

1. 단어 삭제 시 `word_state`와 `attempt`의 해당 기록도 함께 삭제한다 (CASCADE). 삭제한 단어의 기록이 날짜별 집계에 남지 않도록 하기 위한 결정이다.
2. 같은 영어 단어(정규화 후 기준)는 한 번만 등록된다 (UNIQUE).
3. 단어 등록 시 `word_state` 행을 함께 만든다 (기본값: 연속 정답 0, 신규, 복습 대상 아님).
4. 답안 한 건마다 `attempt` 행을 하나 추가한다. 재시험으로 같은 단어를 여러 번 답해도 행이 각각 생긴다.
5. 연속 정답 수는 답안마다 갱신한다. 정답이면 +1, 오답이면 0으로 초기화한다 (FR-02.4).

---

## 5. 인덱스 (성능 참고)

단어 수가 수백 개 이하이므로 별도 인덱스는 필요하지 않다. 다음 조회가 느려지면 추가한다.

| 대상 | 인덱스 (안) | 이유 |
|------|-------------|------|
| `word_state.in_review` | 필요 시 추가 | 복습 대상 조회 |
| `attempt.attempted_at` | 필요 시 추가 | 날짜별 기록 조회 |
