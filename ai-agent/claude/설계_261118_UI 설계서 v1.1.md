# 스마트보카 UI 설계서

**파일 위치**: `ai-agent/claude/설계_261118_UI 설계서 v1.1.md`
**작성일**: 2026-10-21
**갱신일**: 2026-11-18
**버전**: v1.1 (확정, 2026-11-18 승인)
**설명**: 교실에서 쓰는 스마트보카의 화면 구성, 흐름, 표시 규칙을 정의한 UI 설계서 (v1.1: 2026-10-28 리디자인 반영)

---

## 1. 설계 원칙

- 교실 프로젝터와 학생 PC 화면에서 모두 읽히도록 글자와 버튼을 크게 한다 (NFR-01).
- 정답과 오답은 색과 글자를 함께 표시한다 (색맹 사용자 고려).
- 한 화면에 할 일 하나만 둔다.
- 외부 폰트와 라이브러리를 쓰지 않는다. 색은 CSS 변수로 관리하고, 밝은 화면과 어두운 화면을 시스템 설정에 따라 전환한다.

---

## 2. 화면 목록

| 화면 ID | 경로 | 이름 | 연결 기능 |
|---------|------|------|-----------|
| S1 | `/` | 홈 | 전체 |
| S2 | `/study` | 학습 | FR-02, FR-03 |
| S3 | `/study/done` | 세션 완료 | FR-04.2 |
| S4 | `/words` | 단어 관리 | FR-01 |
| S5 | `/report` | 학습 기록 | FR-04 |

모든 화면 위에 상단 바가 있다 (4절 공통 레이아웃).

---

## 3. 화면 흐름

```
S1 홈 ──[학습 시작]──▶ S2 학습 ──(마지막 문제 다음)──▶ S3 세션 완료 ──[홈으로]──▶ S1
 │
 └── 학습할 것이 없으면 S2 진입 시 "오늘 할 학습이 없습니다" 표시 후 S1로 복귀
```

상단 바는 모든 화면에서 같은 위치에 있다.

- 로고 → S1
- 학습 → S2
- 단어 관리 → S4
- 학습 기록 → S5

---

## 4. 공통 레이아웃

- 상단 바: 로고 마크 "S"와 "스마트보카", 메뉴 3개 (학습, 단어 관리, 학습 기록).
- 본문: 카드 단위로 묶는다. 제목은 `h1`, 카드 안의 소제목은 `h2`.
- 알림: 등록, 수정, 삭제 결과와 오류 메시지를 본문 맨 위에 한 줄로 표시한다. 성공은 `✓`, 오류는 `!`로 시작한다 (6절).
- 반응형: 폭 720px 이하에서는 한 열로 배치한다.

## 5. 화면별 구성

### S1 홈

```
┌──────────────────────────────────────┐
│  오늘도 한 단계씩, TOEIC 단어           │
│  오늘의 학습                           │
│          [ 학습 시작 → ]               │
│                                      │
│  [등록 단어 100 개] [복습 대상 12 개]     │
│  [오늘 신규 진행 0 / 20  ▭▭▭▭▭▭▭▭]      │
└──────────────────────────────────────┘
```

- 서로 다른 뜻의 단어가 4개 미만이면 "학습 시작" 버튼 대신 "단어 등록하기 →" 버튼(S4 연결)과 안내 문구 "서로 다른 뜻의 단어를 4개 이상 등록해야 학습을 시작할 수 있습니다."를 표시한다 (ADR-004).
- 통계 3개:
  - 등록 단어: 전체 단어 수
  - 복습 대상: 오늘 복습 후보 수 (데이터 설계서 3절)
  - 오늘 신규 진행: `일일 목표 - 남은 목표` / 20, 진행 막대 표시 (소수점 버림)

### S2 학습

```
┌──────────────────────────────────────┐
│  [신규]                        1 / 20 │
│  ▭▭▭▭▭▭▭▭▭▭▭▭▭▭▭▭▭▭▭▭▭▭▭▭▭▭▭▭▭▭▭▭▭▭      │
│                                      │
│                approve               │
│          알맞은 뜻을 고르세요             │
│  [1] 승인하다                          │
│  [2] 사과                              │
│  [3] 바나나                            │
│  [4] 포도                              │
│                                      │
│  (결과 문구)                           │
│  (예문, 학습 단어 강조)                  │
│                         [ 다음 → ]     │
└──────────────────────────────────────┘
```

- 블록 칩: `신규` 또는 `복습`. 복습 칩은 다른 색으로 구분한다.
- 진행 표시: 블록 안에서 처음 나온 단어의 순서 `n / N`과 진행 막대. 틀린 단어의 재출제는 순서에 포함하지 않는다 (FR-02.3).
- 보기는 4개. 버튼을 누르거나 숫자 키 1~4로 바로 제출한다. 제출 후 보기는 모두 비활성화한다.
- 결과 표시 (제출 후 1초 이내, NFR-01):
  - 정답: "정답입니다!" 문구, 초록 배경. 고른 보기와 정답 보기를 초록으로 표시한다.
    - 복습 블록에서 맞혔지만 연속 정답이 3회 미만이면 문구 뒤에 "연속 3번 맞혀야 복습이 끝납니다"를 덧붙인다.
  - 오답: `오답입니다. 정답은 "뜻" — 이 세션 안에서 다시 나옵니다` 문구, 빨간 배경. 고른 보기는 빨강, 정답 보기는 초록으로 표시한다.
- 예문: 답을 낸 뒤 예문이 있으면 표시한다. 학습 단어는 `mark`로 강조한다. 예문이 없으면 영역을 숨긴다.
- 다음: "다음 →" 버튼 또는 Enter 키.
  - 세션의 마지막 문제였으면 S3로 이동한다.
  - 그 밖에는 같은 화면을 새로 불러와 다음 문제를 출제한다.
- 키보드: 답하기 전에는 1~4, 답한 뒤에는 Enter로 다음 문제.

### S3 세션 완료

```
┌──────────────────────────────────────┐
│  🎉 오늘의 학습 완료                    │
│  수고했어요. 틀린 단어는 다음 복습에서       │
│  다시 만나요.                          │
│                                      │
│  [학습 단어 20 개] [정답률 85.0 %] [완벽 암기 48 개] │
│  복습 대기 32 개                       │
│                                      │
│          [ 홈으로 ]                    │
└──────────────────────────────────────┘
```

- 세션 완료 정보는 방금 끝난 세션이 있을 때만 보인다. 그 밖에 직접 접근하면 S1로 보낸다.
- 정답률은 소수 첫째 자리까지 `%`로 표시한다 (5절 표시 규칙과 통일).

### S4 단어 관리

```
┌──────────────────────────────────────┐
│  새 단어 등록                           │
│  영어 [________] 뜻 [________]           │
│  예문 [__________________] [ 추가 ]      │
│                                      │
│  단어 목록                             │
│  총 100개                              │
│  영어      뜻       예문         [저장] [삭제] │
│  [approve] [승인하다] [The manager...] [저장] [삭제] │
│  ...                                   │
└──────────────────────────────────────┘
```

- 영어와 뜻은 필수, 예문은 선택이다.
- 영어는 저장 시 앞뒤 공백을 지우고 소문자로 바꾼다. 중복이면 "이미 등록된 단어입니다."를 표시하고 저장하지 않는다.
- 수정: 별도 화면이 없다. 목록의 행 안에서 값을 고치고 "저장"을 누른다. 성공하면 "단어를 수정했습니다."를 표시한다.
- 삭제: 브라우저 확인 창을 띄운다. 문구는 "단어를 삭제하면 관련 학습 기록도 함께 삭제됩니다. 계속할까요?"이다 (프로세스 설계서 6절).
- 목록이 비어 있으면 "등록된 단어가 없습니다."를 표시한다.
- 등록 성공 메시지는 "단어를 등록했습니다.", 삭제 성공 메시지는 "단어를 삭제했습니다."이다.

### S5 학습 기록

```
┌──────────────────────────────────────┐
│  학습 기록                             │
│  [완벽 암기 48 개] [복습 대기 32 개]       │
│                                      │
│  날짜         학습 단어   문제 수   정답률  │
│  2026-11-18      20        20     85.0 %  │
│  2026-11-17      20        24     78.5 %  │
│                                      │
│          [ 홈으로 ]                    │
└──────────────────────────────────────┘
```

- 날짜는 최근순으로 정렬한다.
- 정답률은 소수 첫째 자리까지 `%`로 표시한다. 답이 없는 날은 `-`로 표시한다.
- 기록이 없으면 "아직 학습 기록이 없습니다. 첫 학습을 시작해 보세요."를 표시한다.

---

## 6. 표시 규칙

| 항목 | 규칙 |
|------|------|
| 글자 크기 | 영어 단어는 가장 크게, 보기는 본문보다 크게 |
| 정답 표시 | 글자와 배경색을 함께 쓴다. 정답은 초록, 오답은 빨강 |
| 숫자 | 정답률은 소수 첫째 자리까지 `%` (S3, S5 공통) |
| 날짜 | `YYYY-MM-DD` |
| 알림 | 본문 맨 위에 한 줄로 표시. 성공은 `✓`, 오류는 `!` 접두어 |
| 테마 | 시스템 설정에 따라 밝은 화면과 어두운 화면 자동 전환 |

**결정 사항 (2026-11-18)**

1. 정답률 자릿수: S3와 S5 모두 소수 첫째 자리로 통일한다.
2. 복습 재출제 안내: 복습 블록에서 맞혔지만 연속 3회 미만이면 결과 문구 뒤에 "연속 3번 맞혀야 복습이 끝납니다"를 덧붙인다 (S2).
3. 알림 구분: 성공은 `✓`, 오류는 `!`로 시작한다. `base.html`의 표시 방식을 이에 맞춘다.
