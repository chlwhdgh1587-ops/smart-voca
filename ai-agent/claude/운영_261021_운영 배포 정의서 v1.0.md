# 스마트보카 운영·배포 정의서

**파일 위치**: `ai-agent/claude/운영_261021_운영 배포 정의서 v1.0.md`
**작성일**: 2026-10-21
**버전**: v1.0
**설명**: 교실 PC에서 스마트보카를 설치, 실행, 백업, 복구하는 절차를 정의한 운영 정의서

---

## 1. 운영 환경

| 항목 | 내용 |
|------|------|
| 실행 위치 | 교실 PC 1대 (로컬) |
| 운영체제 | Windows 11 (개발 환경과 동일) |
| 런타임 | Python 3.11, Flask 3.x |
| 데이터 저장 | `data/smartvoca.db` (SQLite 파일 1개) |
| 접속 주소 | `http://127.0.0.1:5000` (같은 PC의 브라우저에서만 접속) |
| 외부 연결 | 없음 |

---

## 2. 설치 절차 (최초 1회)

1. Python 3.11을 설치한다. Windows에서 Microsoft Store 스텁(`WindowsApps\python.exe`)을 쓰면 안 된다.
2. 프로젝트 루트에서 `python -m pip install -r requirements.txt`를 실행한다.
3. `python src/seed_words.py`를 실행한다. 기초 단어 100개가 적재된다.
4. 적재 결과에 "등록 100개, 중복 건너뜀 0개, 잘못된 행 0개"가 나오는지 확인한다.

---

## 3. 실행 절차

1. 프로젝트 루트에서 `python src/app.py`를 실행한다.
2. 콘솔에 Flask 시작 메시지가 나오면 브라우저에서 `http://127.0.0.1:5000`을 연다.
3. 종료는 콘솔에서 Ctrl+C를 누른다.

**주의**: 진행 중인 세션은 서버 메모리에 있다. 종료하면 미완료 세션은 다음 실행 때 닫힌다. 복습 대상과 연속 정답 수는 DB에 저장되어 있으므로 유지된다 (프로세스 설계서 1절, 4절).

---

## 4. 백업

| 항목 | 방법 | 주기 (안) |
|------|------|-----------|
| 학습 데이터 | 앱을 끈 상태에서 `data/smartvoca.db`를 다른 폴더에 복사 | 수업이 끝날 때마다 |
| 단어 목록 | `data/words_public.csv`는 저장소에 보관 | 변경 시 |

복원은 앱을 끈 상태에서 백업 파일을 `data/smartvoca.db`로 덮어쓰는 것이다. 덮어쓰기 전에 현재 파일을 따로 보관한다.

---

## 5. 장애 대응

| 증상 | 원인 (추정) | 대응 |
|------|-------------|------|
| `python`을 찾을 수 없음 | Store 스텁 또는 PATH 문제 | Python 3.11을 설치하고 `python --version`으로 확인 |
| `ModuleNotFoundError: flask` | 패키지 미설치 | `python -m pip install -r requirements.txt` 실행 |
| 학습 시작 시 "서로 다른 뜻의 단어를 4개 이상" 안내 | 단어 부족 또는 뜻 중복 | 단어 관리 화면에서 단어를 추가하거나 뜻을 구분해 수정 |
| 페이지가 "오늘 할 학습이 없습니다"만 표시 | 오늘 신규 목표 완료, 복습 대상 없음 | 정상 동작. 다음 날 다시 확인 |
| 포트 5000 사용 중 오류 | 다른 프로그램이 같은 포트 사용 | 이전 `app.py` 창을 닫거나 PC를 재부팅 |
| DB 파일이 손상되어 열리지 않음 | 비정상 종료 등 | 백업을 복원한다. 백업이 없으면 `data/smartvoca.db`를 지우고 2장 3번부터 다시 실행한다. 학습 기록은 모두 사라진다 |

---

## 6. 모니터링과 로그

- 별도 로그 파일은 만들지 않는다. 오류는 실행 콘솔에 출력된다.
- 상태 확인은 홈 화면의 "복습 대상", "오늘 신규 남은 목표" 수치와 학습 기록 화면으로 한다.

---

## 7. 배포

- 배포 서버는 없다. 교실 PC에 프로젝트 폴더를 복사하고 2장 설치 절차를 따른다.
- 새 버전은 폴더를 교체하기 전에 `data/smartvoca.db`를 백업한다.
