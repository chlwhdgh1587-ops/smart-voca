# 스마트보카 환경 분석서

**파일 위치**: `ai-agent/claude/분석_261021_환경 분석서 v1.0.md`
**작성일**: 2026-10-21
**버전**: v1.0 (초안)
**설명**: 스마트보카와 유사한 학습 도구, 기술 환경, 외부 데이터, 관련 제약을 정리한 환경 분석서

> **표기 규칙**: `[검증 필요]`는 일반적인 지식으로 적었으며 실제 서비스 정책이나 라이선스는 확인하지 않은 사항이다.

## 1. 개요

- **목적**: 유사 학습 도구의 방식을 참고해 스마트보카의 범위와 기능을 확인하고, 외부 데이터와 기술 환경 제약을 파악한다.
- **범위**: 개인용 객관식 영어 단어 암기 학습 도구. 사용 환경은 교실.
- **참고 문서**: 기획서(`기획_261021_스마트보카 v1.0.md`), 요구사항 명세서(`분석_261021_요구사항 명세서 v1.0.md`), 현황 분석서(`분석_261021_현황 분석서 v1.0.md`)

---

## 2. 유사 시스템 비교

| 시스템 | 특징 (일반적 내용) | 스마트보카와의 관계 |
|--------|--------------------|---------------------|
| Anki | 간격 반복(Spaced Repetition) 기반 플래시카드 `[검증 필요]` | 복습 주기 방식 참고. 스마트보카는 단순한 다음 날 복습으로 한정 |
| Quizlet | 플래시카드와 객관식 등 여러 학습 모드 제공 `[검증 필요]` | 객관식 출제 방식 참고 |
| 일반 단어장 앱 | 단어 등록, 뜻 확인, 학습 기록 제공 `[검증 필요]` | 단어 등록과 학습 기록 기능 참고 |

**시사점**
- 스마트보카는 객관식, 같은 세션 재시험, 다음 날 복습, 연속 3회 정답 판정으로 기능을 단순화한다.
- 여러 학습 모드나 계정 기능은 과제 범위에서 제외한다 (기획서 4.2 제외 범위).

## 3. 기술 환경

| 항목 | 현황 |
|------|------|
| 기술 스택 | 미정 (설계 단계에서 결정) |
| 실행 환경 | 미정 (설계 단계에서 결정) |
| 교실 사용 조건 | 교실 환경에서 사용 (사용자 확정). 로컬 실행이므로 네트워크가 필요 없다 |
| 개발 도구 | 미정 |

기술 스택과 실행 환경은 요구사항 명세서 7장 확정 사항에 따라 설계 단계에서 정한다.

---

## 4. 외부 데이터

| 항목 | 내용 |
|------|------|
| 초기 단어 데이터 | 직접 작성한 기초 영단어 100개 (요구사항 명세서 NFR-05) |
| 목록 선정 | 직접 작성 (외부 자료 미사용) |
| 사용 조건 | 직접 작성한 목록이므로 외부 이용 조건 제약이 없다 |
| 데이터 형식 | 영어 단어와 뜻으로 구성 (요구사항 명세서 용어 정의) |

---

## 5. 법규 및 보안 제약

| 항목 | 제약 |
|------|------|
| 개인정보 | 실명, 학번 등 개인 식별 정보를 저장하지 않는다 (NFR-03) |
| 학습 기록 | 개인용 학습 기록만 저장하며, 외부로 전송하지 않는다 (ADR-002) |
| 저장소 | 소스와 데이터에 비밀 정보를 넣지 않는다 (CLAUDE.md 코드 규칙 5) |

---

## 6. 종합 시사점

1. 기술 스택과 실행 환경은 설계 단계에서 확정해야 한다.
2. 초기 단어 데이터는 직접 작성하므로 외부 이용 조건 확인은 필요 없다. 단, 단어 수를 늘릴 때는 출처를 기록한다.
3. 기능 범위는 요구사항 명세서 FR-01~04로 한정한다.
