## 4. 수동 확인 항목 (M-01~M-09)

자동 테스트로 확인할 수 없는 화면 항목이다. 2026-11-18에 Flask 테스트 클라이언트 점검 스크립트(`ai-agent/scripts/261118-수동확인_M01_M09.py`)로 HTML 응답과 흐름을 확인했다. 브라우저에서만 보이는 동작은 "부분"으로 남기고, 사용자가 브라우저에서 한 번 더 확인해야 한다.

| ID | 화면 | 확인 내용 | 결과 (2026-11-18) |
|----|------|-----------|------|
| M-01 | S1 홈 | 단어가 4개 미만이면 학습 시작 버튼 대신 안내가 나온다 | 통과. 4개 미만은 안내와 등록 버튼, 5개(뜻 5종)는 학습 시작 버튼 |
| M-02 | S2 학습 | 보기 버튼을 누르면 1초 이내에 정답 또는 오답이 표시된다 | 부분. 서버 응답 약 7 ms (1회 측정). 브라우저 표시 시간은 미측정 |
| M-03 | S2 학습 | 키보드 1~4 키로 보기를 고를 수 있다 | 부분. 키 처리 코드 확인. 실제 키 입력은 브라우저 미확인 |
| M-04 | S2 학습 | 오답이면 정답이 표시되고 같은 세션 안에서 다시 나온다 | 통과. 응답에 정답 포함, 같은 단어가 블록 끝에 재배치 |
| M-05 | S2 학습 | 다음 버튼이 마지막 문제 뒤에 세션 완료 화면으로 이동한다 | 통과. 마지막 응답 `session_finished`, 완료 화면 표시 (화면 이동 버튼 동작은 브라우저 미확인) |
| M-06 | S4 단어 관리 | 등록, 수정, 삭제가 동작하고 삭제 전에 확인 창이 뜬다 | 부분. 등록·수정·삭제 알림과 삭제 확인 문구 확인. 확인 창 팝업은 브라우저 미확인 |
| M-07 | S4 단어 관리 | 같은 영어 단어를 등록하면 "이미 등록된 단어입니다"가 나온다 | 통과. 대소문자·공백 무시, `!` 접두어로 표시 |
| M-08 | S5 학습 기록 | 기록이 없으면 "아직 학습 기록이 없습니다"가 나온다 | 통과 |
| M-09 | 전체 | 앱을 껐다가 다시 켜도 학습 기록과 복습 대상이 유지된다 | 통과 (같은 프로세스에서 앱 객체를 새로 만든 방식. 실제 프로세스 재시작은 미실행) |
