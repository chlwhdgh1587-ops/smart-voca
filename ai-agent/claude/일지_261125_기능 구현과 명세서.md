## 1. 요청

- 기능 구현을 먼저 하고 명세서까지 진행한다.
- 검색·CSV 가져오기·시험 등 빠진 기능을 모두 넣고, 도전 기능(로그인, 다른 계정 이력, 설정)도 구현한다.
- 제공 CSV 2,000개 파일은 이 PC에 없다. 저장소의 100개 파일로 검증하고, 가져오기 기능은 그대로 둔다.
- 중복 단어는 건너뛴다. 시험 형식은 4지선다, 단답형, OX 세 가지를 쓴다.

## 2. 처리

**DB (스키마 v2)**
- `word_state`, `study_session`, `attempt`에 `user_id`를 추가하고 기본키를 `(user_id, word_id)`로 바꿨다.
- 새 테이블: `app_user`, `user_setting`, `exam_session`, `exam_item`.
- v1 → v2 이관은 `db.init_schema`가 자동으로 한다. 실제 백업 DB(단어 120, 상태 120, 세션 2, 답안 51)로 행 수와 외래키를 검증했다.
- 백업: `data/backup_smartvoca_before_v2_261125.db` (Git 제외).

**서비스**
- `word_service`: 검색(`list_words`), CSV 가져오기(`import_words_csv`). 중복은 건너뛰고 기존 뜻을 덮어쓰지 않는다.
- `study_service`: 계정별 세션, 일차(`current_day_number`), 자주 틀린 단어 복습 섞기, 복습 비율, 카드 목록(`todays_new_words`). 전역 세션 변수는 계정별 딕셔너리로 바꿨다.
- `exam_service` (신규): 가중치 출제, 3가지 형식, 방향 섞기, 문항 단위 이력. 상태는 DB에 저장해 재시작 후에도 이어 풀 수 있다.
- `report_service`: 계정별 집계, 진도(`progress_summary`), 시험 추이(`exam_trend`), 자주 틀린 단어(`weak_words`).
- `settings_service` (신규): 하루 학습량, 복습 비율, 시험 기본값 검증과 저장.
- `auth_service` (신규): 가입, 로그인 확인(werkzeug 해시), 공개 여부.

**화면**
- 카드, 시험(설정, 문항, 결과), 단어 검색과 CSV 업로드, 학습 기록 확장, 로그인과 가입, 설정, 사용자 목록과 보기 전용 기록.
- 로그인 게이트(`before_request`)로 로그인하지 않은 요청은 로그인 화면으로 보낸다. `/api/`는 401.
- 세션 쿠키는 `SameSite=Lax`, `HttpOnly`.

**테스트**
- 기존 22개를 새 시그니처에 맞추고 47개를 추가했다. 전체 69개 통과.
- 추가 파일: `test_exam_service`, `test_word_import_search`, `test_study_extras`, `test_settings_and_migration`, `test_app_routes`, `test_auth_service`, `test_report_extras`.
- 실제 백업 DB 복사본으로 앱을 띄워 가입 전후 모든 화면이 200을 반환하고, 기존 기록이 첫 가입 계정에 붙는 것을 확인했다.

**문서 (작업본, `ai-agent/claude/`)**

- `설계_261125_데이터 설계서 v1.2.md`: 스키마 v2 테이블 정의, 질의 규칙, 이관 규칙.
