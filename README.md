# 스마트보카 (Smart Voca)

영단어를 4지선다, 단답형, OX로 외우는 웹 단어장입니다. 하루 신규 단어를 공부하고, 연속 3회 정답이면 완벽 암기로 봅니다. 틀린 단어는 같은 세션에서 맞힐 때까지 다시 나오고, 다음 날 복습 블록에서 다시 확인합니다. 시험, 카드 암기, 학습 통계, 회원별 기록을 제공합니다.

- 작성자: 260134 최종호
- 기말 과제(AI기반 프로그래밍) 산출물
- 요구사항 명세서: `docs/분석_261125_기말과제 요구사항 명세서 v1.0.md`
- 작업 방식과 요구사항 ID 추적: `CLAUDE.md`

## 고른 DB

**SQLite** (표준 라이브러리 `sqlite3`). 파일 위치는 환경변수 `DB_PATH`로 정합니다. 없으면 `data/smartvoca.db`를 씁니다. 처음 실행할 때 테이블을 자동으로 만들고, 예전 스키마 DB는 자동으로 옮깁니다.

## 실행 방법

### 1. 교실 PC에서 직접 실행 (Python 3.11)

```bash
python -m pip install -r requirements.txt
python src/seed_words.py      # 기초 단어 100개 적재 (최초 1회, 선택)
python src/app.py             # http://127.0.0.1:5000 접속
```

처음 접속하면 회원 가입 화면이 열립니다. 가입 후 `단어 관리`에서 단어를 등록하거나 CSV를 가져옵니다. 학습은 서로 다른 뜻의 단어가 4개 이상 있어야 시작됩니다.

### 2. Docker 이미지로 실행 (서버와 같은 조건)

```bash
docker build -t smartvoca .
docker run --rm -p 8080:8080 -e SECRET_KEY=change-me -v smartvoca-data:/data smartvoca
```

접속: `http://127.0.0.1:8080`

- `SECRET_KEY`를 주지 않으면 기동할 때 무작위 값을 만듭니다. 이 경우 서버를 재시작하면 로그인이 풀립니다.
- 데이터는 컨테이너의 `/data/voca.db`에 저장됩니다. 볼륨을 붙이면 재시작 후에도 남습니다.
- 컨테이너는 UID 10001로 실행되며 root 권한을 쓰지 않습니다. 워커는 1개로 실행합니다.

## 주요 화면

| 메뉴 | 기능 |
|------|------|
| 학습 | 오늘의 복습과 신규 단어를 4지선다로 학습 |
| 카드 | 오늘의 신규 단어를 한 장씩 보며 암기 (기록 없음) |
| 시험 | 문제 수, 방향(영→한, 한→영, 섞기), 형식(4지선다, 단답형, OX) 선택. 중간에 끊겨도 이어 풀 수 있음 |
| 단어 관리 | 등록, 검색, 수정, 삭제, CSV 가져오기 (UTF-8, `english,meaning` 머리글, 중복은 건너뜀) |
| 학습 기록 | 현재 일차, 암기한 단어, 날짜별 학습량, 시험 추이, 자주 틀린 단어 |
| 사용자 | 공개로 설정한 회원의 학습 기록을 보기만 할 수 있음 |
| 설정 | 하루 학습량, 복습 비율, 시험 기본값, 기록 공개 여부 |

## 환경변수

| 이름 | 기본값 | 설명 |
|------|--------|------|

## 알려진 한계

- 단어장은 모든 회원이 함께 씁니다. 단어를 고치면 모두에게 보입니다.
- 기존 학습 기록은 DB를 옮길 때 첫 번째 가입 계정에 붙습니다.
- 로그인 시도 횟수 제한과 별도 CSRF 토큰은 없습니다. 세션 쿠키는 `SameSite=Lax`로 설정했습니다.
- 학습 세션은 서버 메모리에 있어서 재시작하면 닫힙니다. 시험은 DB에 있어 이어 풀 수 있습니다.

## 프로젝트 구조

```
src/            Flask 앱 (app.py, db.py, *_service.py, templates/, static/)
data/           기초 단어 CSV (words_public.csv). DB 파일은 Git에 올리지 않음
tests/          단위·통합 테스트 (unittest)
docs/           승인된 설계·분석 산출물 (이전 버전은 docs/old/)
ai-agent/       작업 기록, 화면 점검, 참고자료
Dockerfile      서버 배포용 이미지 정의
```

## 테스트

```bash
python -m unittest discover -s tests
```

Flask가 없으면 화면 통합 테스트(`test_app_routes`)는 건너뜁니다. 나머지 서비스 테스트는 표준 라이브러리만으로 실행됩니다.
